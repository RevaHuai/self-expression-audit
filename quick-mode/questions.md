# 快速模式题库

## 概述

快速模式（体检）从 108 题中精选 10 道最高密度题目，覆盖 6 个板块，约 25 分钟完成。

**选题原则：** 每题平均揭示 2.5 个结构维度，在最少的问题量内暴露最多的结构信息。

**快速模式 vs 核心/深度模式的区别：**
- 快速模式每题只问 1 轮，不做深度追问
- 快速模式的答案标记 depth: "quick"
- 升级到核心/深度模式时，已答过的题会被追加追问（upgraded: true）

## 10 道精选题目

### 1. 最欣赏的 3 位表达者

**来源模块：** D0 北极星（Q1）
**揭示维度：** 身份认同 + 审美 + aspiration + 信念来源

**简化追问规则：**
- 如果回答是"最有名的"而非"最触动的" → 追问：「我说的不是最有名的，是最触动你的」
- 只给 1-2 位 → 追问：「第三位呢？强迫自己多找一个」
- 用"他们都"开头 → 追问：「他们各自不同在哪？每个人最独特的是什么？」

**快速模式不追问：**
- 北极星溯源（Q2-Q6 的深层追溯）
- 共同点的深度分析

---

### 2. 完整定位陈述

**来源模块：** D0 北极星（Q13）
**揭示维度：** 身份 + 受众 + 核心价值 + 领域 + aspiration

**简化追问规则：**
- 任何一个空填不上 → 追问：「没关系，空着也没关系——但空着说明那里有值得探索的东西」
- "服务/内容形式"过于笼统 → 追问：「具体的形式——长文？对话？视频？」
- "受众"过于宽泛 → 追问：「最想触动的那个具体的人是什么样的？」

**快速模式不追问：**
- 定位陈述的深层意义
- 追问"如果换成别人的答案"

---

### 3. Ikigai 交叉点

**来源模块：** D0 北极星（Q18）
**揭示维度：** 深层驱动力 + 理想与现实落差 + 未满足的需求

**简化追问规则：**
- 四个圆没有交集 → 追问：「没关系，交集不在现在——你在往哪个方向移动？」
- 交集过于完美 → 追问：「真的吗？如果诚实地看，哪个圆最小？」
- 只提到热爱和擅长 → 追问：「世界需要什么？你能从中获得什么？」

**快速模式不追问：**
- 交集的具体画面
- 和领域定位的关系

---

### 4. 反共识观点

**来源模块：** D1 信念（Q19）
**揭示维度：** 信念 + 领域深度 + 价值观 + 与主流的距离

**简化追问规则：**
- 回答过于温和 → 追问：「如果必须选边站，你站在哪边？」
- 说"其实大家都这么想" → 追问：「你真的这么认为？」
- 只给观点不给原因 → 追问：「为什么你确信？有什么经历或证据？」

**快速模式不追问：**
- 反共识的后果（是否被人反对过）
- 如何在公开场合捍卫

---

### 5. 最大主张

**来源模块：** D1 信念（Q33）
**揭示维度：** 最大主张 + 身份 + aspiration

**简化追问规则：**
- 主张过于宽泛 → 追问：「压缩到一句话，只能有一个核心动作」
- 主张是引用他人的 → 追问：「那是 xxx 的主张——你自己的呢？」
- 和 Q19 的回答高度重叠 → 正常——记录这个重叠

**快速模式不追问：**
- 主张的防御场景
- 反对者的角度

---

### 6. 怎么向朋友介绍

**来源模块：** D2 表达机制（Q34）
**揭示维度：** 表达机制 + 真实性 + 自我认知 + 声音

**简化追问规则：**
- 使用了专业术语 → 追问：「不要用专业术语——就聊天」
- 描述过于简短 → 追问：「你朋友会追问『具体做什么』——你怎么回答？」
- 描述变成了自我介绍 → 追问：「不要说你叫什么——说你做什么事」

**快速模式不追问：**
- 这段话和实际作品的一致性
- 如果是改编过的追问

---

### 7. 自然 gravitate 的表达形式

**来源模块：** D2 表达机制（Q38）
**揭示维度：** 形式偏好 + 媒介直觉 + 表达本能

**简化追问规则：**
- 说"我都行" → 追问：「不——如果没有任何限制，你拿起什么最自然？」
- 说是"视频"但实际产出全是文字 → 追问：「你说 gravitate 视频，但你所有的作品都是文字——哪个是真实的你？」
- 说"我最擅长的" → 追问：「gravitate 不是擅长——是你不自觉就会去做的」

**快速模式不追问：**
- 为什么 gravitate 这个形式
- 从未尝试过的形式

---

### 8. 绝对不会碰的表达

**来源模块：** D6 绝对禁区（Q86）
**揭示维度：** 禁忌 + 身份边界 + 价值观 + 恐惧

**简化追问规则：**
- 回答变成了"不擅长" → 追问：「不是『不擅长』——是『那不是我』」
- 过于具体 → 追问：「那个形式背后代表什么？它触碰了什么？」
- 说"没什么" → 追问：「一定有的——有没有一种表达方式你看到就觉得『这不是我』？」

**快速模式不追问：**
- 底线的来源（Q92-Q95 的溯源）
- 违反禁区的含义

---

### 9. 看到别人做时想"我永远不会那样"

**来源模块：** D6 绝对禁区（Q88）
**揭示维度：** 价值观禁忌 + 深层排斥 + 身份边界

**简化追问规则：**
- 说"没什么" → 追问：「一定有的——想想最近看到的某个表达，你心里冒出的第一个念头是什么？」
- 说了一个但无法解释 → 追问：「为什么是『永远不会那样』？那个『那样』是什么？」
- 说了一个具体行为 → 追问：「那个行为背后是什么态度？那种态度为什么让你如此排斥？」

**快速模式不追问：**
- 边界的来源
- 底线故事

---

### 10. 什么让你不信任表达者

**来源模块：** D7 危险信号（Q96）
**揭示维度：** 不信任的信号 + discernment + 自身标准 + 审美 + 领域认知

**简化追问规则：**
- 说"没什么" → 追问：「一定有——想想最近让你觉得『这人不可信』的一个表达者」
- 过于理性 → 追问：「不只是结构问题——你身体有什么反应？不舒服？排斥？」
- 只提到他人的问题 → 追问：「你自己呢？你有没有过被信任然后又失望的表达？」

**快速模式不追问：**
- 被骗的详细经历（Q98）
- 装 vs 真的区别（Q99）
