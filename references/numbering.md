## 有效题 vs 编号跨度

| 概念 | 值 | 说明 |
|------|-----|------|
| **有效提纲题** | **95** | 有题面、可进 coverage 的题 |
| **编号跨度** | Q1–Q108 | 历史编号保留，便于旧 state / 引用 |
| **空号（故意）** | **Q61–Q73** | 原 D4 已删除；**禁止生成、禁止补题** |
| **缺失模块** | D4 | 不存在；勿在 progress 中建 D4 |

|------|------|------|

## 模式覆盖量

| 模式 | 必覆盖数 | 组成 |
|------|----------|------|
| `quick` | **10** | Q1, Q13, Q18, Q19, Q33, Q34, Q38, Q86, Q88, **Q96** |
| `core` | **70** | D0+D1+D2+D5+D6 全部（**不含** D3、**不含** D7） |
| `deep` | **95** | core + D3(Q49–60) + D7(Q96–108) |

### quick 含 Q96、core 不含 D7

这是**刻意设计**，不是疏漏：

- quick 需要一刀「辨别力」快照 → 抽 Q96  
- core 专注坐标系 + 愿景/机制/节律/禁区，把 D7 整板留给 deep  
- **升级含义：**
  - quick→core：Q96 **保留在 rawData**，但 **退出 core 的 coverage**（不要求 core 完成 D7）
  - quick→deep 或 core→deep：Q96 若已有答案 → coverage 标 `done`，可按需深化 followUps，不重问除非用户要深化
  - core→deep：补 D3 全部 + D7 中除已 done 外的题

脚本：`scripts/outline_data.py` 的 `OUTLINE` 必须与上表一致。

## 对外表述模板

**推荐：**

- 「有效提纲 **95** 题（编号保留至 Q108；Q61–Q73 为空号）」
- 「quick 10 / core 70 / deep 95」
- 「提纲是覆盖清单，不是播放列表」

**禁止：**

- 「108 道核心题全部要答」
- 「core 完成即含 D7」
- 自动生成 Q61–Q73 或 D4 模块

## 与 state 的关系

- `rawData` 键允许 Q1–Q108 中任意**有效** ID；空号写入应视为错误  
- `coverage` 只含当前模式 OUTLINE 中的 ID  
- 从 quick 升 core 时：重建 coverage 为 core 清单；Q96 可留在 rawData 与 dialogue，但不进入 core coverage  
- `progress` 只含 D0,D1,D2,D3,D5,D6,D7（无 D4）
