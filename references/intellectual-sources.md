# 思想来源与设计原则

> 完整梳理的压缩版。题库「像什么」与「明确不是什么」写在这里，避免被误读成量表或品牌 Canvas。

## 显式理论锚点（模块正文已点名）

| 来源 | 落点 | 用法 |
|------|------|------|
| Fred Polak《The Image of the Future》 | D1、北极星 | 未来意象 → 行动 → 现实 → 新意象 |
| Peter Senge 正/负愿景 | D1 + D6 | 创造与躲避成对 |
| Approach / Avoidance Motivation | D6、四句话 | 趋近 + 逃避 = 完整立场 |
| Utopia / Dystopia 传统 | D6 反愿景 | 把趋势推到极端的「不要的世界」 |
| Ikigai 四圆 | D0 Q18 | 驱动力诊断，非鸡汤完成态 |
| 70/20/10 比例 | D5 Q80 | 已验证 / 迭代 / 实验 |

## 方法家族（结构同构，未逐条挂名）

质化深度访谈、苏格拉底追问、构念两极对比、定位句式的反表演用法、媒介/形式暴露主体、体感审美、鉴赏力（discernment）、个人版思想史溯源与知识图谱、假设—验证式「原型锚点」流程。

## 明确不是

- Big Five / MBTI 等常模量表  
- 临床心理或道德诊断  
- 完整 Jung 十二型词典（见 `proto-system`：仅有锚点流程）  
- 严格学术思想史考证  

## 设计原则

1. 最少问题暴露最多结构  
2. D0 坐标系优先  
3. 愿景 ∥ 反愿景  
4. 行为暴露大于自我标榜  
5. 边界定义身份  
6. 矛盾是信号（tension 优先于整洁）  
7. 结论要有证据链  
8. 北极星去人名化  
9. 提问与分析引擎分离（north-star-exploration）  
10. 题号是索引，不是播放列表（见 `interview-engine.md`）
