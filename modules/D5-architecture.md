## 板块说明

D5 挖掘被访谈者的内容节律和组织逻辑——在不同时间尺度上如何组织表达，长短内容的关系，以及表达背后的结构性策略。

**这一板块在挖什么：**
你怎么在不同时间尺度组织表达（周/月/季/年）；长短内容的关系；表达节律；70/20/10 规则。

**依赖关系：**
轻依赖 D0。可以插在 D0 之后的任意位置运行。不需要 D1/D2 的语境。

## 问题列表

### Q74-Q76：时间维度组织

**Q74.** 你每周会表达什么？不是"发几篇帖子"，而是你每周想传达的那个核心是什么？

**Q75.** 你每月会表达什么？和每周的有什么不同？深度增加了什么？

**Q76.** 你每季度和每年呢？更长的时间维度里，你想完成什么更深层的事？

### Q77-Q79：长短内容关系

**Q77.** 你的长内容（长文、深度作品）和短内容（短文、片段）之间是什么关系？它们是同一个思想的不同切片，还是完全不同的东西？

**Q78.** 短内容会为长内容服务吗？长内容会催生短内容吗？还是一者独立于另一者存在？

**Q79.** 有没有一种"核心内容"——一个大的思想或作品——你所有的其他表达都是它的注脚或延伸？

### Q80-Q82：70/20/10 与节律

**Q80.** 如果你把表达内容分成三类——70% 是你擅长且验证过的、20% 是在此基础上的迭代、10% 是纯实验——你现在的比例是什么样的？理想的比例呢？

**Q81.** 你如何让自己保持表达的节律？有没有什么机制或习惯帮助你在灵感枯竭时仍然输出？

**Q82.** 你会在什么时机暂停表达——是完成一个大作品后、转换方向时、还是感到疲惫时？暂停本身对你意味着什么？

### Q83-Q85：重复与演进

**Q83.** 你有没有一种"一直在说同一件事"的感觉？如果是，那件事是什么？如果不是，你最怕变成什么样的人？

**Q84.** 你的表达方式在过去一年里变化最大的是什么？什么没有变？

**Q85.** 五年后回头看，你希望你的表达方式和现在有什么不同？

## 追问规则

### Q74：每周表达的核心

**触发追问的条件：**
- 说"发几篇帖子" → 追问：「不是数量——是你每周想传达的那个核心是什么？」
- 说"不知道" → 追问：「回看你上周的帖子或作品——它们围绕一个中心吗？那个中心是什么？」
- 过于具体 → 追问：「那个核心是一个话题、一个情绪、还是一个行动？」

### Q75：每月表达

**触发追问的条件：**
- 说"和每周差不多" → 追问：「深度呢？每月的东西和每周的有什么深度的区别？」
- 说"没什么月度计划" → 追问：「没关系——你每月结束时回头看，什么留了下来？什么消失了？」
- 把月度变成了季度 → 追问：「月和周之间——那个过渡是什么？」

### Q76：季度和年度

**触发追问的条件：**
- 说"没什么计划" → 追问：「不用计划——你年底回头看，什么让你觉得『这一年没白过』？」
- 过于具体 → 追问：「那个深层的事——它和你的身份有关吗？」

### Q77：长短内容关系

**触发追问的条件：**
- 说"差不多" → 追问：「如果长内容和短内容是同一个东西的不同切片，为什么还要分成两个？」
- 说"完全不同的" → 追问：「那你的长内容和短内容的作者是同一个人吗？」
- 无法区分 → 追问：「想象你把所有短内容拼起来——它能变成一个长内容吗？如果拼不起来，说明什么？」

### Q78：长短内容的互相服务

**触发追问的条件：**
- 说"没想过" → 追问：「有没有一个长内容是从短内容里长出来的？反过来有没有？」
- 说"都是独立的" → 追问：「那它们为什么属于同一个你？连接点是什么？」
- 只提到单向服务 → 追问：「有没有双向的？长内容催生短内容？」

### Q79：核心内容

**触发追问的条件：**
- 说"没什么核心" → 追问：「真的吗？有没有一个想法你反复在说、每次换个角度？」
- 说了核心但和 D0 的回答不一致 → 记录到 tensionLog
- 核心过于宽泛 → 追问：「那个核心能不能用一句话说清？」

### Q80：70/20/10 比例

**触发追问的条件：**
- 说"没分过" → 追问：「不用精确——你现在的表达，大概多少是重复自己、多少是新东西、多少是实验？」
- 比例是 100% 安全区 → 追问：「10% 的实验呢？你真的在做吗？」
- 理想比例和现实差距巨大 → 追问：「那个差距在告诉你什么？」

### Q81：保持节律的机制

**触发追问的条件：**
- 说"靠灵感" → 追问：「灵感不来的时候呢？你怎么办？」
- 说"靠自律" → 追问：「那个自律机制具体是什么？一个习惯？一个系统？」
- 过于具体 → 追问：「那个机制背后是什么？恐惧？热爱？责任？」

### Q82：暂停表达的时机

**触发追问的条件：**
- 说"从不暂停" → 追问：「不可能——你至少会在完成一个大作品后停一下吧？那个停下来的时刻是什么感觉？」
- 说"感到疲惫时" → 追问：「那个疲惫是身体的还是精神的？你怎么分辨？」
- 说"没什么特殊意义" → 追问：「暂停本身就是意义——你不需要做什么，只是停下来。那是什么感觉？」

### Q83：一直在说同一件事

**触发追问的条件：**
- 说"没什么同一件事" → 追问：「那如果你所有的作品放在一起，有一条线穿过去——那是什么？」
- 说是"同一件事"但与 D17 的回答不一致 → 记录到 tensionLog
- 说"最怕变成重复的人" → 追问：「重复是坏事吗？还是『重复但没有深度』才是坏事？」

### Q84：过去一年的变化

**触发追问的条件：**
- 说"没什么变化" → 追问：「真的？语言呢？语气呢？你选择写什么不写什么？」
- 说"变化很大" → 追问：「那个最大的变化——是从什么时候开始的？什么触发的？」
- 只提到外部因素 → 追问：「不是你变了——是外部变了。你自己呢？」

### Q85：五年后的希望

**触发追问的条件：**
- 说"不知道" → 追问：「不用精确——你希望五年后的自己看现在的东西，觉得什么？」
- 过于具体 → 追问：「那个『不同』——是更好了，还是不一样了？」
- 和 D16 的回答高度重叠 → 正常——记录这个重叠
