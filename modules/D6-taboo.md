## 板块说明

D6 挖掘被访谈者的绝对边界——那些"我绝对不会做的事"。这个板块的价值在于：**一个人的边界定义了他的身份。**

**这一板块在挖什么：**
绝不做的事；绝不越的线；绝不关联的人/表达风格。

**层级结构：**
D6 的问题组织遵循一个从个人边界到世界愿景的递进层级：

```
个人边界（Personal Boundary）
  ↓  "我绝不做什么"
身份边界（Identity Boundary）
  ↓  "那样我就不是我了"
反愿景（Anti-Vision）
  ↓  "我绝不希望世界变成什么样"
```

**理论锚点：**

**乌托邦 / 反乌托邦传统**：Vision 对应 Utopia（Preferred Future），Anti-Vision 对应 Dystopia（Future to be Avoided）。但 Dystopia 不是简单的"我不喜欢"——它是一种把现实趋势推演到极端后展示最终会变成什么。反愿景如果做得好，实际上是在做一种小型的「个人未来情景推演」。例如：不是"我讨厌算法"，而是"如果算法依赖趋势继续十年，最终会不会出现一个人无法独立判断任何事情的社会？"

**趋近—逃避结构（Approach / Avoidance Motivation）**：愿景是趋近方向（approach），反愿景是逃避方向（avoidance）。两者必须同时存在——只有愿景没有反愿景，北极星会变成"我不想成为某种人"，这是逃跑而不是站立。只有反愿景没有愿景，北极星会变成"我只是在抵抗"，没有建设性方向。

**依赖关系：**
高依赖 D0。禁区问题需要前面建立的信任积累才有意义——如果一个人还没清楚自己是谁，他定义的"禁区"大概率是模仿来的。

**重要约束：D6 不能在 D0 之前或同时运行。** 必须等 D0 完成后再进入。

反愿景尤其需要 D1 的愿景作为对照：只有清楚自己想推动什么，才能真正明确自己想逃离什么。愿景和反愿景是一对阴阳——它们共同定义了一个人的完整价值立场。

## 问题列表

### Q86-Q88：绝不做的

**Q86.** 有什么表达方式或内容类型是你绝对不会碰的？不是你"不擅长"，而是你觉得"那不是我"？

**Q87.** 有什么话题或立场是你绝对不会公开表达的——不是因为害怕，而是因为那不符合你的核心？

**Q88.** 有什么表达行为是你看到别人做时会想"我永远不会那样"？为什么？

### Q89-Q91：绝不关联的

**Q89.** 有什么人或群体是你绝对不会和你的名字关联在一起的？不是讨厌，而是"那样我就不是我了"。

**Q90.** 有什么商业行为或变现方式是你绝对不会用来承载你的表达的？为什么？

**Q91.** 如果你的表达方式被别人"借用"或模仿了，你的感受是什么？什么样的借用会让你感到被冒犯？

### Q92-Q95：边界的来源

**Q92.** 这些"不"是从哪里来的——是你天生就有的直觉，还是某段经历教会你的？

**Q93.** 有没有一个"底线故事"——某件事或某个人的行为让你决定"我绝不过那条线"？

**Q94.** 如果你违反了其中一条自己的禁区，你觉得那意味着什么？

**Q95.** 这些禁区里有你会定期重新审视的吗？还是它们已经成了你身份的一部分，不需要再检查了？

## 追问规则

### Q86：绝对不会碰的表达

**触发追问的条件：**
- 回答变成了"不擅长" → 追问：「我说了不是『不擅长』——是『那不是我』。你擅长但不会做的事是什么？」
- 过于具体（只提到一个形式）→ 追问：「那个形式背后代表什么？它触碰了什么让你排斥？」
- 说"没什么" → 追问：「一定有的——想想看，有没有一种表达方式你看到就觉得『这不是我』？」
- 理由过于理性 → 追问：「不只是理性判断——你的身体有什么反应？不舒服？抵触？」

**追问方向：**
- 「如果必须做一次那种表达，你会觉得自己是谁？」
- 「这个『不』保护了什么？」
- 「如果这种表达方式成为主流，世界会变成什么样？」（反愿景延伸）

### Q87：绝对不会公开表达的话题

**触发追问的条件：**
- 说"因为害怕" → 追问：「不是因为害怕——是因为那不符合你的核心。区别在哪？」
- 说"没什么" → 追问：「一定有——不是隐私，是立场。你有没有一个立场你永远不会公开站？」
- 理由过于理性 → 追问：「那个立场如果被逼你表态，你会说什么？不说的是什么？」

### Q88：看到别人做时想"我永远不会那样"

**触发追问的条件：**
- 说"没什么" → 追问：「一定有的——想想最近看到的某个表达，你心里冒出的第一个念头是什么？」
- 说了一个但无法解释 → 追问：「为什么是『永远不会那样』？那个『那样』是什么？」
- 说了一个具体行为 → 追问：「那个行为背后是什么态度？那种态度为什么让你如此排斥？」

**反愿景延伸追问：**
- 「如果这种行为成为常态，你觉得世界会失去什么？」

### Q89：绝对不会关联的人或群体

**触发追问的条件：**
- 说"没什么" → 追问：「不是讨厌——是『那样我就不是我了』。有没有一个群体，如果有人说『你和他们一样』，你会感到被冒犯？」
- 说了一个具体群体 → 追问：「为什么那个群体让你觉得『那样我就不是我了』？他们代表了什么？」
- 理由过于攻击性 → 不阻止，但记录：「这个回答很强烈——它在说什么？」

**反愿景延伸追问：**
- 「如果这个群体代表了未来的主流，你觉得世界会变成什么样？」

### Q90：绝对不会用的变现方式

**触发追问的条件：**
- 说"没什么" → 追问：「不是『不想赚』——是『绝不会用这种方式』。想想看」
- 说了一个方式但理由是"不赚钱" → 追问：「不是钱的问题——如果那个方式超级赚钱，你会做吗？」
- 理由过于理性 → 追问：「用那种方式变现，你觉得自己会变成谁？」

**反愿景延伸追问：**
- 「如果这种变现方式成为行业标准，你觉得表达生态会变成什么样？」

### Q91：被冒犯的借用

**触发追问的条件：**
- 说"不介意" → 追问：「真的？有没有一种模仿会让你觉得『这不是致敬，是偷』？」
- 说了一个方式但无法解释 → 追问：「那种借用和另一种借用的区别是什么？边界在哪？」
- 说"只要给我 credit 就行" → 追问：「Credit 之外呢？有没有一种借用哪怕给了 credit 你还是不舒服？」

### Q92：边界的来源

**触发追问的条件：**
- 说"天生的" → 追问：「天生的直觉——那个直觉第一次出现在什么时候？」
- 说"经历教会的" → 追问：「那个经历具体是什么？那时候你多大？」
- 说"不知道" → 追问：「不一定要追溯到源头——但想想看，这些『不』最早是什么时候出现的？」

### Q93：底线故事

**触发追问的条件：**
- 说"没什么故事" → 追问：「一定有的——有没有一个时刻你心里说『我绝不过那条线』？」
- 故事是第二手的 → 追问：「是你亲眼见的还是听说的？如果是听说的，你自己有没有类似的经历？」
- 故事过于平淡 → 追问：「那个时刻你身体有什么反应？愤怒？恶心？恐惧？」

### Q94：违反禁区的含义

**触发追问的条件：**
- 说"没什么" → 追问：「真的？如果你今天做了你昨天说绝对不会做的事，你觉得那意味着什么？」
- 说"只是改变了主意" → 追问：「改变主意和违反禁区是不一样的。违反是你明知不该做但还是做了——那意味着什么？」
- 过于自贬 → 不阻止，但记录：「这个回答在暴露什么？」

### Q95：定期审视的禁区

**触发追问的条件：**
- 说"都会审视" → 追问：「真的？有没有一个你觉得永远不会变？」
- 说"都不会变" → 追问：「真的吗？你五年前和现在的禁区一样吗？」
- 说"都会变" → 追问：「那你现在定义的禁区可靠吗？」

**反愿景收敛触发条件：**
当系统检测到 D6 的回答中出现以下信号时，自动触发反愿景收敛追问：
- 回答中提到了"世界变成""未来变成""所有人都在"等宏观描述
- 回答的禁忌和 D1 的愿景形成对照（愿景说"我希望人们..."，禁区说"我绝不看到人们..."）
- 回答中出现了对"那个世界"的描述性语言

**反愿景收敛追问：**
- 「你描述的『那个世界』——如果它真的出现了，你觉得最糟糕的是什么？」
- 「这个反愿景和你自己的愿景之间有什么关系？你在抵抗什么，以保护什么？」
- 「如果有一天你的反愿景实现了，你觉得你自己的表达还有什么意义？」
