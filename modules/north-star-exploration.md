# 北极星深度探索（North Star Deep Exploration）

> 围绕用户已有的北极星，进行深度探索与分析。不是提问模块，不是 D0 的延续——它是一个**独立的分析能力**，读取 D0 已有的数据，输出综合分析报告。

**核心原则：北极星不是你最崇拜的人，而是在你长期的欣赏、学习、追溯和实践中反复出现的一种方向感。更锋利地说：北极星，是你在别人身上反复认出的自己。**

---

## 1. 能力定义

### 1.1 这是什么

北极星深度探索是一个**分析引擎**。它：

- **读取** D0 板块已有的问答数据（`rawData` 中 D0 的 18 道题答案）
- **分析** 用户的北极星候选、影响图谱、共振模式
- **输出** 综合分析报告，包括北极星卡片、影响图谱、学习路径推荐
- **不问新问题**——不增加新的问答环节

### 1.2 触发条件

用户在对话中说：
- "深度探索我的北极星"
- "探索我的影响图谱"
- "北极星分析"
- 或任何明确指向"对已有北极星进行深度分析"的表述

### 1.3 前置检查

**D0 必须完成。** 如果 D0 未完成，引导用户先完成 D0：

```
你的北极星深度探索需要基于 D0（北极星与身份定位）的完整数据。
目前 D0 只完成了 [X]/18 题。

建议你先完成 D0，完成后可以直接对我说：
"深度探索我的北极星"

要继续 D0 吗？
```

**检查逻辑：**
- 读取状态文件 `expression-audit-state.json`
- 检查 `progress.D0.status` 是否为 `"complete"`
- 如果为 `"partial"` 或 `"not_started"`，显示上述引导语
- 如果为 `"complete"`，进入分析流程

## 2. 分析流程

### 2.1 总览

```
输入：D0 rawData（18道题答案）+ 状态文件
  ↓
步骤 1：共振检测
  ↓ 输出：共振日志、共振点、候选北极星
步骤 2：影响图谱构建
  ↓ 输出：影响图谱（人物/书籍/理论/传统）
步骤 3：北极星发现循环复盘
  ↓ 输出：收敛分析、属性提取、去人名化方向
步骤 4：知识考古
  ↓ 输出：学习路径推荐、素材分层
步骤 5：北极星卡片生成
  ↓ 输出：完整的北极星卡片
步骤 6：压力测试验证
  ↓ 输出：五项检验结果
最终输出：综合分析报告
```

### 2.2 步骤 1：共振检测

**输入：** D0 的 Q1-Q6 答案（表达者、故事、共同点、灵感来源、第三层第四层、最意外的名字）

**分析逻辑：**

1. **提取候选人物列表**
   - 从 Q1 中提取用户提到的所有表达者
   - 从 Q4-Q5 中提取用户提到的灵感来源、影响者
   - 从 Q6 中提取用户提到的"最意外的名字"

2. **检测每人的共振层级**
   - 扫描每道题答案中的信号词
   - 标记为 admiration / recognition / identification / direction

3. **追踪共振升级**
   - 如果同一人物在多个题目中被提及，追踪层级变化
   - 例如：Q1 说"他很厉害"（admiration）→ Q2 说"他说出了我想说的话"（recognition）

4. **标记共振点**
   - 如果某个节点的共振层级达到 identification 或 direction，标记为共振点

5. **识别候选北极星**
   - 如果存在 direction 层级的共振，直接标记为候选北极星
   - 如果只有 identification，标记为强候选
   - 如果只有 recognition，标记为潜在候选

**输出：**

{

    {
      "id": "R1",
      "person": "Naval",

    {

### 2.3 步骤 2：影响图谱构建

**输入：** D0 的 Q4-Q5 答案（灵感来源、第三层第四层）

**分析逻辑：**

1. **提取影响链**
   - 从 Q4 中提取"一阶北极星 → 直接影响源"
   - 从 Q5 中提取"二阶 → 三阶"的影响链
   - 构建完整的图谱结构

2. **标注节点属性**
   - 每个节点标注：name, type, order, resonance, materialType
   - materialType 按三阶结构标注：form（一阶）/ method（二阶）/ source（三阶）

3. **标记交汇点**
   - 如果多条影响链指向同一个节点或思想，标记为交汇点
   - 交汇点 = 用户思想谱系的核心

4. **识别缺失节点**
   - 如果影响链在某层中断（用户不知道某人的影响源），标记为"待探索"

### 2.4 步骤 3：北极星发现循环复盘

**输入：** D0 的全部 18 道题答案

**分析逻辑：**

1. **映射到 9 轮循环**
   - 检查每道题答案在发现循环中的角色
   - 评估循环的完成度

2. **提取属性（Round 5）**
   - 从影响链中提取反复出现的品质
   - 抽象为 3-5 个候选方向

3. **去人名化（Round 6）**
   - 删除所有人物名字
   - 形成去人名化的候选方向陈述

4. **过去验证（Round 7）**
   - 从 Q15（故事如何塑造表达）中提取行为证据
   - 检查是否有自发行为的案例

5. **压力测试（Round 8）**
   - 从 Q18（Ikigai）中推断可持续性
   - 从 Q12（最不希望被描述）中推断边界

### 2.5 步骤 4：知识考古

**输入：** 影响图谱 + 共振检测结果

**分析逻辑：**

1. **素材分层**
   - 按三阶结构为图谱中的节点标注素材类型
   - 一阶：form（表达形式、产品形态）
   - 二阶：method（思考框架、工作方法）
   - 三阶：source（原典、历史、哲学）

2. **学习路径推荐**
   - 直接阅读清单：用户北极星反复引用的书籍
   - 前置阅读清单：理解影响源需要的背景知识
   - 对比阅读清单：多条影响链的差异来源
   - 下一步探索：沿着影响链的下一个节点

3. **交汇点分析**
   - 如果多条影响链交汇于同一个思想，标记为"核心原材料"
   - 这是用户思想谱系中最值得深入学习的方向

**输出：**

### 2.6 步骤 5：北极星卡片生成

**输入：** 所有分析步骤的输出

**分析逻辑：**

1. **核心方向**：从收敛分析中提取一句话陈述（去人名化）
2. **被什么人吸引**：从共振检测中提取影响链
3. **反复追求的属性**：从属性提取中提取 3-5 个核心属性
4. **不想成为**：从 Q12 中提取反方向
5. **过去的证据**：从 Q15 中提取行为案例
6. **未来投射**：从 Q18 中推断长期方向

**输出：** 完整的北极星卡片（见第 3 节）

---

### 2.7 步骤 6：压力测试验证

**输入：** 北极星卡片 + D0 数据

**分析逻辑：**

1. **五项检验推断**
   - 从 Q12（禁区）推断：是否有强烈的边界意识？（无观众测试）
   - 从 Q18（Ikigai）推断：是否有内在驱动力？（无回报测试）
   - 从 Q1（欣赏的人）推断：是否有身份表演倾向？（无名测试）
   - 从 Q4-Q5（灵感来源）推断：是否有自主探索倾向？（无模板测试）
   - 从 Q15（故事）推断：是否有长期坚持的证据？（十年测试）

2. **检测矛盾**
   - 如果 Q1 说"我想成为 Naval"但 Q12 说"我不希望被描述为'装'"，检查是否矛盾
   - 如果 Q18 的 Ikigai 交集很窄，检查是否有逃避倾向

**输出：** 五项检验的推断结果

## 5. 与 D0 追问规则的联动

### 5.1 知识考古触发

当用户回答 D0 的 Q4（灵感来源）或 Q5（第三层第四层）时，如果答案包含：
- 人物提及（"A 影响了我的看法"）
- 书籍/文本提及（"那本书改变了我的…"）
- 理论/框架提及（"那个理论说…"）

系统自动激活知识考古追问，追溯影响来源。

### 5.2 共振检测触发

当用户回答 D0 的 Q1-Q6 时，系统实时检测共振信号：
- Admiration："他很厉害"
- Recognition："他说出了我想说的话"
- Identification："这就是我"
- Direction："我愿意走十年"

### 5.3 剥离式追问触发

当用户回答任何提及人物的题目时，系统自动触发剥离追问：
- "如果这个人不存在了，你真正想留下的是什么？"
- "把这个人从答案里去掉，剩下的那句话是什么？"

## 6. 北极星深度探索 vs D0 板块的关系

| 维度 | D0 板块 | 北极星深度探索 |
|---|---|---|
| 性质 | 提问模块 | 分析引擎 |
| 输入 | 用户问答 | D0 的已有数据 |
| 输出 | 问答记录 | 综合分析报告 |
| 交互方式 | 逐题对话 | 一次输出完整分析 |
| 触发时机 | 审计开始时 | D0 完成后 |
| 是否问新问题 | 是 | 否 |
| 依赖关系 | 无（入口模块） | 依赖 D0 完成 |

**关键区别：** D0 是**发现过程**（通过问答收集材料），北极星深度探索是**分析过程**（从已有材料中提炼洞察）。两者互补，但不重叠。

## 7. 使用场景

### 场景 1：完成核心模式后

用户完成 D0-D6 的 70 道题后，说"深度探索我的北极星"。

系统读取 D0 的 18 道题答案，运行 6 步分析流程，输出综合分析报告。

### 场景 2：完成快速模式后

用户只完成快速模式的 10 道题后，说"深度探索我的北极星"。

系统检测到 D0 数据不足，引导用户：
```
你的北极星深度探索需要 D0 的完整数据。
目前只有 3 道 D0 题的答案（Q1, Q13, Q18）。

快速模式的答案不足以支撑深度分析。
建议你：
1. 继续核心模式（再完成 15 道 D0 题 + 其他模块）
2. 或者至少补充 D0 的 Q2-Q6, Q4-Q5（灵感来源追踪）

要继续 D0 吗？
```

### 场景 3：单独导出北极星卡片

用户在完成深度探索后，说"导出我的北极星卡片"。

系统只输出第 3.2 节的北极星卡片（不输出完整分析报告）。

## 8. AI 执行协议

### 8.1 前置检查

```
1. 读取状态文件 expression-audit-state.json
2. 检查 progress.D0.status
3. 如果 status != "complete"：
   - 显示引导语
   - 提供选项：继续 D0 / 稍后再说
4. 如果 status == "complete"：
   - 读取 rawData 中 D0 的 18 道题答案
   - 进入分析流程
```

### 8.2 分析执行

```
1. 步骤 1：共振检测（分析 Q1-Q6）
2. 步骤 2：影响图谱构建（分析 Q4-Q5）
3. 步骤 3：北极星发现循环复盘（分析全部 18 题）
4. 步骤 4：知识考古（基于影响图谱）
5. 步骤 5：北极星卡片生成（整合所有分析结果）
6. 步骤 6：压力测试验证（推断五项检验）
7. 生成综合分析报告（第 3.1 节格式）
8. 更新状态文件（第 4 节格式）
```

### 8.3 输出规则

- 分析结果基于已有数据，不做无根据的推断
- 如果某步骤数据不足，标注为"数据不足，建议补充 D0 的 XX 题"
- 如果存在矛盾，明确标注并说明可能的解释
- 报告末尾附带"建议"部分，告诉用户下一步可以做什么

### 8.4 与编译器的衔接

北极星深度探索的输出可以被编译器使用：

- `northStarCard` → 编译为报告中的北极星卡片章节
- `knowledgeGraph` → 编译为影响图谱摘要
- `learningPath` → 编译为学习路径推荐章节
- `resonanceLog` → 编译为张力检测的一部分

这意味着用户在完成 D0 后可以：
1. 直接运行北极星深度探索
2. 或者继续完成其他模块，最后通过编译器生成完整报告

两种路径产出的北极星卡片内容相同，但深度探索路径更快（不需要完成 70-95 题）。
