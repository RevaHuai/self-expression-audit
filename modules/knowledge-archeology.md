# 知识考古能力

> 北极星板块的增强功能。当用户在 D0 问答中提到某个人物、书籍或思想时，系统自动激活追溯追问，帮助用户沿着影响链向上挖掘，找到构成其表达思想的"原材料"。

**核心原则：不要学习你喜欢的人，要学习"使你喜欢的人成为他自己"的东西。**

---

## 1. 能力边界

**知识考古是追问扩展层，不是独立模块。** 它不增加新的问题，而是在用户回答 D0 现有 18 题时，自动检测是否触发知识考古追问。

### 触发条件

以下任一条件满足时，激活知识考古追问：

| 触发信号 | 典型表述 | 激活时机 |
|---|---|---|
| 人物提及 | "A 影响了我的看法"、"A 的观点让我…" | 任何 D0 问答中 |
| 书籍/文本提及 | "那本书改变了我的…"、"我反复读…" | 任何 D0 问答中 |
| 理论/框架提及 | "那个理论说…"、"我从那个框架里…" | 任何 D0 问答中 |
| 溯源自述 | "他受谁影响"、"他的来源是…" | Q4、Q5 直接触发 |
| 共振信号 | "他说出了我想说的话"、"这就是我" | 任何 D0 问答中 |

### 关闭条件

用户出现以下信号时，停止知识考古追问，回归 D0 主线：

- "我不想继续追了" / "这个话题先到这里"
- 回答开始变得空洞或敷衍
- 已经追溯了 3 层以上
- 用户明显失去兴趣（简短回答、转移话题）

**知识考古不是必须完成的任务，而是根据用户的回答动态触发的探索路径。** 它的目的是帮助用户发现，不是测试用户的博学程度。

---

## 2. 四层追溯深度

知识考古沿着影响链向上追溯，最多 4 层。每层有不同的追问重点。

### 第一层：直接影响源（1 步距离）

**目标：** 找出用户欣赏的人物/作品直接受到谁的影响。

**追问模板：**

```
你提到 A。A 在公开场合提到过哪些影响他的人？
有没有一本书、一个理论、或另一个人，是 A 反复引用的？
A 说"我深受…影响"——那个"…"是谁或什么？
```

**产出：**
- A 的直接导师或灵感来源（2-5 个名字）
- A 反复引用的书籍/文章/理论

**示例：**
```
用户：我欣赏 Naval。
系统：Naval 在多次采访中提到过谁对他的思考影响最大？
用户：Paul Graham 和 Nassim Taleb。
系统：Naval 有没有反复引用过某本书或某个理论？
用户：他说过 antifragility 这个概念来自 Taleb 的书，还有 iterated games 来自 Peter Thiel。
```

### 第二层：间接影响源（2 步距离）

**目标：** 找出直接影响源的思想来源。

**追问模板：**

```
你说 B 影响了 A。那 B 的思想从哪里来？
B 受谁影响？B 的"北极星"是谁？
B 反复引用的原典或思想家是谁？
```

**产出：**
- B 的思想来源（2-4 个名字）
- 可能的共同引用（多个影响源都提到的原典）

**示例：**
```
用户：Paul Graham 影响了 Naval。
系统：Paul Graham 的思考方式从哪里来？他提到过哪些影响他的人？
用户：他没怎么直接说，但他写过的很多想法来自 Bertrand Russell 和 Richard Feynman。
系统：Taleb 呢？
用户：Taleb 引用了很多 Michel de Montaigne 和 Seneca。
```

### 第三层：共同源头（3 步距离）

**目标：** 找出多个影响链交汇的共同源头。

**追问模板：**

```
你现在追踪到的这几条链——A→B→C 和 A→D→E
有没有一个名字，同时出现在两条链上？
这些人共同推崇的"元知识"是什么？
```

**产出：**
- 影响图谱中的交汇节点（高优先级——说明这是用户思想谱系的核心）
- 跨链共同引用的原典

**示例：**
```
系统：Naval → Taleb → Montaigne / Seneca
      Naval → Graham → Russell / Feynman
      这几条链有没有交汇点？
用户：Taleb 和 Graham 都提到过 probabilistic thinking。还有 Seneca 和 Russell 都在写"如何思考"这件事。
系统：这个交汇点很有意思——probabilistic thinking 和"如何思考"都在你的溯源链上反复出现。
```

### 第四层：原典与时代背景（最远距离）

**目标：** 触达影响链的源头——原典、历史时期、哲学传统。

**追问模板：**

```
这些人最终都追溯到哪些"元典"？
有没有一个历史时期或思想运动，构成了他们共同的知识环境？
Montaigne 在写什么的时候，Taleb 在读什么？
```

**产出：**
- 影响链的源头原典（书籍、文本、哲学体系）
- 时代背景和问题意识
- 可能的历史运动或思想传统

**示例：**
```
系统：你的溯源链最终到了 Montaigne 和 Seneca——都是斯多葛传统的。
你想过追溯 Montaigne 的来源吗？
用户：Montaigne 引用了很多古希腊和古罗马的哲学家……我觉得这已经够远了。
系统：够远了。但注意到一个问题——你的影响链从现代 Silicon Valley（Naval）一路追到
      古罗马（Seneca），跨度 2000 年。中间连接的东西是什么？
用户：大概是"独立的思考者"这个传统吧——不依附于任何体制，自己建立知识体系的人。
```

## 3. 影响图谱输出格式

知识考古的最终产出是一张**影响力图谱**，不是一棵树。一个人可以同时属于多条影响链。

### 图谱结构

```
                    ┌── 人物 ──┐
                    │          │
                    ├── 书籍 ──┤
                    │          │
      [共振点] ←──  ├── 理论 ──┤  ←── 影响关系
                    │          │
                    ├── 时期 ──┤
                    │          │
                    └── 传统 ──┘
                         ↑
                         │
                       喜欢
                         │
                        A（一阶北极星）
                         ↑
                       影响
                         │
                        B（二阶）
                         ↑
                       影响
                         │
                        C（三阶）
                         ↑
                       影响
                         │
                        D（源头）
```

### 节点标注

每个节点标注以下信息：

| 字段 | 说明 | 示例 |
|---|---|---|
| `name` | 名称 | Paul Graham |
| `type` | 类型 | person / book / theory / era / tradition |
| `order` | 影响阶数 | 1（一阶）/ 2（二阶）/ 3（三阶）/ 0（源头） |
| `resonance` | 共振层级 | admiration / recognition / identification / direction |
| `materialType` | 素材类型 | form / method / source |
| `source` | 信息来源 | Q4 / Q5 / 用户自述 |
| `keyWorks` | 关键作品 | 《Essays》《Hackers & Painters》 |
| `keyIdeas` | 核心思想 | startup ideas, independent thinking |
| `influencedBy` | 影响来源 | [节点列表] |

### 图谱规则

1. **一个节点可以有多条 incoming edge**（被多个来源影响）
2. **一个节点可以有多条 outgoing edge**（影响多个后续节点）
3. **共振点可以有多个**——用户可能有 2-3 个产生强烈共鸣的节点
4. **图谱不追求完整**——只追踪用户主动提及的路径，不做无限扩展
5. **源头节点（order: 0）不需要继续追溯**——除非用户主动要求

## 4. 素材分层标注

知识图谱中的每个节点按三阶结构标注素材类型：

### 一阶素材：Form（形式素材）

**来源：** 一阶北极星的直接产出

| 素材类型 | 示例 |
|---|---|
| 表达方式 | 写作风格、演讲风格、视觉风格 |
| 产品形态 | 产品设计、交互方式 |
| 内容形式 | 文章结构、视频节奏、播客格式 |
| 审美偏好 | 配色、排版、氛围 |
| 工作方式 | 日程、创作习惯、发布节奏 |

### 二阶素材：Method（方法素材）

**来源：** 二阶北极星的方法论

| 素材类型 | 示例 |
|---|---|
| 思考框架 |  mental models、决策框架 |
| 工作方法 | 创作流程、研究方法 |
| 认知体系 | 世界观、知识组织方式 |
| 产品方法 | 从想法到产品的路径 |
| 写作方法 | 从观察到文本的转化 |

### 三阶素材：Source（原始素材）

**来源：** 三阶北极星的原典和思想源头

| 素材类型 | 示例 |
|---|---|
| 原典 | 书籍、论文、经典文本 |
| 历史事件 | 塑造思想的时代背景 |
| 哲学问题 | 反复被追问的根本问题 |
| 科学发现 | 提供认知基础的知识 |
| 文学作品 | 提供叙事范式的文本 |
| 哲学/宗教传统 | 提供价值框架的传统 |
| 社会现实 | 提供问题意识的社会语境 |
| 人类经验 | 跨越时代的普遍经验 |

## 5. 学习路径推荐

基于知识图谱，系统为用户生成学习路径：

### 5.1 直接阅读清单

**规则：** 列出用户北极星直接引用或推荐的书籍/文章。

**触发条件：** 用户在 Q4-Q5 中提到某个人物反复引用某本书。

**输出格式：**
```
📚 直接阅读清单
（这些人是你北极星反复引用的源头）

1. 《Antifragile》— Nassim Taleb
   为什么：你的北极星 Naval 多次提到这个概念改变了他的思考方式
   预计难度：中等
   建议先读：第 1-3 章（核心概念）和第 9 章（可选性的价值）

2. 《The Beginning of Infinity》— David Deutsch
   为什么：Naval 在播客中称之为"改变人生的书"
```

### 5.2 前置阅读清单

**规则：** 如果用户想理解二阶北极星的思想，需要先理解哪些基础概念或背景知识。

**触发条件：** 二阶影响源的理论需要特定背景知识才能理解。

**输出格式：**
```
📚 前置阅读清单
（理解这些思想之前，需要先建立的知识基础）

1. 概率论基础
   为什么：理解 Taleb 的 antifragility 需要概率直觉
   建议：不需要读教科书，从《The Signal and the Noise》开始
```

### 5.3 对比阅读清单

**规则：** 如果用户有多个北极星或影响源，推荐对比阅读以理解差异。

**触发条件：** 多条影响链存在明显不同的立场或方法论。

**输出格式：**
```
📚 对比阅读清单
（这些人在回答同一个问题，但答案不同——理解差异就是理解你自己的立场）

1. Taleb（ antifragility ） vs. Thiel（ zero to one ）
   同一个问题：如何在不确定的世界中创造价值
   差异：Taleb 强调适应性，Thiel 强调规划性
   你的位置：从你的回答看，你更倾向于 Taleb 的路径
```

### 5.4 下一步探索

**规则：** 基于用户当前的知识谱系，推荐下一个值得探索的方向。

**触发条件：** 知识图谱中存在明显的"下一个节点"——用户已经理解当前层，可以继续向上追溯或横向扩展。

**输出格式：**
```
🔭 下一步探索

1. 横向：Montaigne 的同时代人
   Montaigne 的《Essays》写于 16 世纪，同时代的思考者还包括:
   - Francis Bacon（ empiricism 的开端）
   - Michel de Montaigne 本人就是 Skepticism 传统的代表
   推荐：先读 Montaigne 的《Essays》选段，再决定是否深入这一时期

2. 纵向：Montaigne 的来源
   Montaigne 大量引用古希腊和古罗马文本：
   - Sextus Empiricus（ Skepticism 的原典）
   - Plutarch（ moral essays ）
   - Seneca（ Stoicism ）
```

## 6. 与北极星发现循环的衔接

知识考古的输出直接成为北极星发现循环的输入：

| 发现循环阶段 | 知识考古贡献 |
|---|---|
| Round 1 捕捉 | 帮助用户发现 3 个以上的候选北极星 |
| Round 2 具体化 | 提供候选人物的具体行为和品质 |
| Round 3 剥离人物 | 从影响链中提取原则而非人物 |
| Round 4 追溯来源 | 直接执行——知识考古的核心功能 |
| Round 5 提取属性 | 从素材分层中提取用户追求的核心属性 |
| Round 6 去人名化 | 删除所有人物名字，形成候选方向 |
| Round 7-8 验证 | 用知识谱系中的行为证据验证 |

**关键衔接点：Round 3（剥离人物）。** 知识考古的最大风险是用户最终得到一个"谁影响了谁"的名单，而不是自己的原则。剥离式追问（见 D0 追问规则规则3）必须在知识考古的每层追溯中同步执行。

## 7. AI 执行协议

### 7.1 激活后的行为模式

当知识考古被激活时，AI 的行为模式改变：

**普通 D0 追问：** 一次一个问题，等待回答后继续。

**知识考古追问：** 进入"考古模式"——连续追问追溯，但不超过 3 轮，不偏离用户的核心兴趣。

### 7.2 考古模式规则

1. **最多追溯 3 层**：超过 3 层后，暂停并问用户"要继续追还是先回到主线？"
2. **每次只追一条链**：如果用户提到了 2-3 个人物，先选共振最强的一条链深入，其他标记为"稍后探索"
3. **每层至少产出 1 个具体名字或作品**：不追溯抽象的"某个传统"，必须有可搜索的具体实体
4. **标记共振点**：在追溯过程中，标记用户产生强烈反应的节点
5. **不强迫**：用户说"不想继续追"时立即停止

### 7.3 考古模式退出

当以下任一条件满足时，退出考古模式，回到 D0 主线：

- 追溯了 3 层以上
- 用户主动说"先回到主线" / "不想继续追了"
- 已经产出 1 张影响图谱
- 连续 2 轮追问没有得到实质性新信息

**退出时的过渡语：**
```
好，溯源先到这里。你刚才追踪到的这条链很有价值——
[简短总结发现]。
我们先回到 D0 的主线，后面的问题可能会让你对这条链有新的理解。
```

## 8. 与其他模块的衔接

| 模块 | 衔接方式 |
|---|---|
| D0 | 知识考古在 D0 中被激活，影响图谱存入 rawData |
| D1 信念 | 影响图谱中的思想家成为 D1 信念题的参照物 |
| D2 表达机制 | 一阶/二阶素材直接影响 D2 的表达方式分析 |
| D3 审美禁区 | 三阶素材中的美学传统成为 D3 的参照 |
| D7 危险信号 | 用户不信任的表达者可能与影响链中的某些节点形成对比 |

知识图谱在 D0 完成后被标记到 `expressionAuditData.knowledgeGraph`，后续模块通过读取这个字段来获取语境底座。
