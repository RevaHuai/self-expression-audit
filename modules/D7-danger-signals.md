## 板块说明

D7 挖掘被访谈者的 discernment（辨别力）——什么让他们立刻不信任一个表达者，以及他们对自己领域的"假货"识别能力。

**这一板块在挖什么：**
什么让你立刻不信任一个表达者；你的领域里「假货」长什么样；抄袭 vs. 生长的区别。

**依赖关系：**
扩展模块，核心完成后可选。D7 的数据用于深化 D0-D6 建立的 discernment 维度。

## 问题列表

### Q96-Q98：不信任的信号

**Q96.** 什么样的表达者会让你立刻产生不信任感？是语气上的什么特质？结构上的什么问题？

**Q97.** 你的领域里，什么样的表达者让你一眼就能看出"他不知道自己在说什么"？信号是什么？

**Q98.** 你有没有过"被骗了"的经历——某个表达者让你觉得他们懂，后来发现他们其实不懂？那是什么样的？

### Q99-Q102：真与假

**Q99.** 在你的领域里，"装"和"真"的最大区别是什么？你怎么在一秒内判断？

**Q100.** 什么样的表达让你觉得是"抄的"而不是"长的"？二者的区别在哪里？

**Q101.** 你见过的最"假"的一种表达风格是什么？它伪装的是什么？

**Q102.** 你有没有过因为"看起来像某种风格"而被人误解的经历？那是什么感觉？

### Q103-Q108：行业诊断

**Q103.** 你的领域里最常见的"表达陷阱"是什么——那种看起来聪明但其实毫无内容的做法？

**Q104.** 有什么表达方式在你的领域里被严重低估了？大多数人没注意到它的价值。

**Q105.** 你领域里有没有一个公认的"好表达"标准，而你私下认为它误导了很多人？

**Q106.** 什么样的表达者会在你的领域里获得不应有的关注？他们在利用什么？

**Q107.** 如果你的表达方式是一面镜子，你希望它反射出什么？你最怕它反射出什么？

**Q108.** 最后一个问题——如果这是你最后一次系统性地梳理你的表达方式，你希望自己最清楚的是什么？

## 追问规则

### Q96：不信任的表达者

**触发追问的条件：**
- 说"没什么" → 追问：「一定有——想想最近让你觉得『这人不可信』的一个表达者」
- 过于理性 → 追问：「不只是结构问题——你身体有什么反应？不舒服？排斥？」
- 只提到他人的问题 → 追问：「你自己呢？你有没有过被信任然后又失望的表达？」

### Q97：不知道自己在说什么的信号

**触发追问的条件：**
- 说"没什么" → 追问：「一定有——那种看起来很专业但你知道他在空转的」
- 过于具体 → 追问：「那个信号是结构上的还是语气上的？能具体描述吗？」

### Q98：被骗的经历

**触发追问的条件：**
- 说"没什么" → 追问：「不是被骗钱——是表达上被骗。那种『我觉得他懂』后来发现『他其实不懂』」
- 过于具体 → 追问：「那个信号你之前为什么没注意到？」
- 说"只是自己太蠢" → 不阻止，但追问：「那个信号是什么？现在你能识别出来吗？」

### Q99：装 vs 真的区别

**触发追问的条件：**
- 说"都一样" → 追问：「不可能——你一定有一秒就能判断的方法」
- 过于理性 → 追问：「不只是理性——你的直觉呢？身体呢？」
- 说"态度" → 追问：「什么态度？具体的——语气？结构？内容？」

### Q100：抄的 vs 长的

**触发追问的条件：**
- 说"都一样" → 追问：「不可能——抄袭和原创你分得出来」
- 过于具体 → 追问：「那个区别是结构上的？内容上的？还是……？」
- 只提到法律层面 → 追问：「不只是法律——是你的感受。抄的东西让你觉得什么？」

### Q101：最假的表达风格

**触发追问的条件：**
- 说"没什么" → 追问：「一定有——那种你觉得『这也有人信』的风格」
- 过于攻击性 → 不阻止，记录
- 只提到一个人 → 追问：「还有呢？第二种？」

### Q102：被误解的经历

**触发追问的条件：**
- 说"没什么" → 追问：「一定有的——你写了/说了什么，别人以为你是另一种风格」
- 过于理性 → 追问：「那是什么感觉？被误解的感觉——不只是『他们理解错了』」
- 说"无所谓" → 追问：「真的吗？如果那个误解影响了别人对你的信任呢？」

### Q103：表达陷阱

**触发追问的条件：**
- 说"没什么" → 追问：「一定有——那种看起来很聪明但其实没内容的做法」
- 过于攻击性 → 不阻止，记录
- 只提到一个人 → 追问：「还有呢？第二种陷阱？」

### Q104：被低估的表达方式

**触发追问的条件：**
- 说"没什么" → 追问：「一定有——那种你觉得『这才是好表达』但大家没注意到的」
- 过于理性 → 追问：「为什么它被低估了？大家忽略了什么？」
- 和自己有关 → 追问：「你自己在用吗？」

### Q105：被误导的好表达标准

**触发追问的条件：**
- 说"没什么" → 追问：「一定有——那种大家都觉得『这就是好表达』但你私底下觉得是错的」
- 过于攻击性 → 不阻止，记录
- 只提到一个人 → 追问：「还有呢？」

### Q106：不应得关注的表达者

**触发追问的条件：**

- 过于攻击性 → 不阻止，记录

**触发追问的条件：**
