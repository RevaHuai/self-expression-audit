## 板块说明

D3 挖掘被访谈者的审美边界——什么让他们感到不适、什么是"活的" vs "死的"表达、以及在审美选择上的不可妥协偏好。

**这一板块在挖什么：**
别人的什么表达行为让你生理不适；什么内容/定位让你觉得敷衍。

**依赖关系：**
扩展模块，核心完成后可选。D3 的数据用于深化 D0-D6 建立的审美维度。

## 问题列表

### Q49-Q52：让你不适的

**Q49.** 看到别人的什么表达方式会让你生理不适——不是"不喜欢"，是"看不下去了"？描述一个具体的例子。

**Q50.** 哪种内容形式、结构或套路你觉得是最严重的"表达敷衍"？为什么？

**Q51.** 你的领域里最常见的一种"不动脑子"的表达方式是什么？你一眼就能识破的那种。

**Q52.** 看到什么样的表达会让你想"这人不真诚"？是语气、结构还是内容上的什么特质？

### Q53-Q56：活着的 vs 死的

**Q53.** 什么样的表达让你感觉是"活的"——有呼吸感、有人的温度、在和你对话？

**Q54.** 什么样的表达让你感觉是"死的"——像从模板里出来的、没有心跳、只是信息的搬运？

**Q55.** 如果你的表达方式有一个"气味"，你认为它闻起来像什么？

**Q56.** 你的领域里，有没有一个你真心觉得"做对了"的表达者？他们做对了什么？跟大多数人错在哪里？

### Q57-Q60：审美选择

**Q57.** 你在视觉审美上有什么不可妥协的偏好？可以具体到颜色、排版、空间感。

**Q58.** 你在内容的"长度"上有什么偏好？太长会让你失去耐心，还是太短让你觉得不够？

**Q59.** 有没有一种内容趋势在你的领域里很流行，但你完全无法理解的？它在流行什么？

**Q60.** 你被什么样的表达标题或开场白吸引？什么样的又让你立刻划走？

## 追问规则

### Q49：生理不适的表达

**触发追问的条件：**
- 说"没什么" → 追问：「一定有的——想想最近刷到的一个让你立刻划走的内容」
- 描述过于理性 → 追问：「不只是『不喜欢』——是『生理不适』。你的身体有什么反应？」
- 说了一个但无法解释 → 追问：「那个表达触碰了你什么？是价值观？审美？还是……？」

### Q50：表达敷衍

**触发追问的条件：**
- 说"没什么" → 追问：「一定有——想想你看到标题就觉得『又是这招』的内容」
- 过于攻击性 → 不阻止，记录：「这个回答很激烈——它在说什么？」
- 只说了一种 → 追问：「还有第二种吗？不同的敷衍方式」

### Q51：不动脑子的表达

**触发追问的条件：**
- 说"没什么" → 追问：「你领域里一定有一种表达方式，所有人都觉得『专业』但你一眼看穿」
- 过于泛化 → 追问：「具体是什么样的？举个例子」

### Q52：不真诚的表达

**触发追问的条件：**
- 说"没什么" → 追问：「一定有的——那种『看起来真诚但其实不是』的表达，特质是什么？」
- 说"语气不对" → 追问：「什么语气？具体是什么样的？」
- 只提到他人 → 追问：「你自己呢？你有没有过表达被别人觉得不真诚的经历？」

### Q53：活的表达

**触发追问的条件：**
- 说"没什么" → 追问：「一定有——那种你在读的时候觉得『对面有个人』的表达，是什么样的？」
- 过于泛化 → 追问：「具体是什么样的？举个例子——谁、做了什么、你怎么感受到的？」
- 说"真诚" → 追问：「真诚有很多种——你感受到的是哪种真诚？」

### Q54：死的表达

**触发追问的条件：**
- 说"没什么" → 追问：「一定有——那种你扫一眼就知道是从模板里出来的」
- 和 Q53 的回答矛盾 → 记录到 tensionLog：「你说『活的』是xxx，『死的』是yyy——但 xxx 和 yyy 的区别是什么？」

### Q55：表达的气味

**触发追问的条件：**
- 说"没什么" → 追问：「不用想太深——如果你的表达是一杯水，它是什么味道的？」
- 过于具体 → 追问：「那个气味让你想起了什么场景？」
- 和 Q53 矛盾 → 正常——气味是活的表达的另一种表达

### Q56：做对了的表达者

**触发追问的条件：**
- 说"没什么" → 追问：「一定有的——你偷偷觉得『这才是表达该有的样子』的人」
- 和 Q1 的回答完全一样 → 正常——记录：「D3 的『做对了』和 D0 的『最欣赏』指向同一个人」
- 不同的人 → 追问：「为什么 D0 里最欣赏的和 D3 里觉得『做对了』的不是同一个人？」
