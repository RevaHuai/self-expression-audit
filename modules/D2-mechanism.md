## 板块说明

D2 挖掘被访谈者的实际沟通方式——不是你以为的，而是你实际怎么做的。这个板块的数据直接用于锚点 2 的精炼。

**这一板块在挖什么：**
你实际怎么沟通的（不是你以为的）；你擅长什么表达形式；你想从其他领域借鉴什么形式；你的用词偏好。

**依赖关系：**
中依赖 D0。需要 D0 的身份语境来理解表达选择的逻辑。

## 问题列表

### Q34-Q37：实际沟通方式

**Q34.** 你怎么向朋友介绍你在做的事情？不要用专业术语，就聊天——这段描述暴露了你真正的表达方式。

**Q35.** 你的表达里最常出现什么类型的信息——观点、故事、数据、提问、比喻、回忆？你更自然地"携带"什么？

**Q36.** 你有没有刻意不在表达中带进某种类型的内容？为什么？

**Q37.** 你表达时默认的"节奏"是什么——是快速抛出多个观点，还是一个深入讲透一件事？

### Q38-Q42：形式与媒介

**Q38.** 你自然 gravitate 的表达形式是什么？写长文、短视频、音频、对话、视觉？你不需要"准备"就能进入状态的形式是哪个？

**Q39.** 哪个领域或行业的表达形式让你眼睛发亮？你最想把那种形式"搬"到自己身上？

**Q40.** 你的文字表达和口头表达有什么本质的不同？哪个更接近真实的你？

**Q41.** 哪种表达形式让你感到最"卡"——明明脑子里有想法，但用那种形式就是说不出来？

**Q42.** 有没有一种你从未尝试过但一直想试的表达形式？是什么阻止了你？

### Q43-Q48：语言与用词

**Q43.** 你的表达中反复出现哪些词或短语？你朋友可能会说"这就是你的口头禅"。

**Q44.** 有没有一些表达方式或框架是你从别人那里学来并内化的？它们已经成为你思考方式的一部分了吗？

**Q45.** 有哪些词、说法或表达框架你永远不会用？不是因为它们不好，而是因为它们让你感到不适。

**Q46.** 你开始一段表达时最自然的方式是什么——提出问题、讲一个故事、抛出一个数据、直接陈述观点？

**Q47.** 你结束一段表达时最自然的方式是什么——总结升华、留一个开放式问题、回到某个主题、戛然而止？

**Q48.** 有没有什么特别的语法、句式或节奏上的偏好？比如喜欢短句、喜欢用括号、喜欢用列表？

## 追问规则

### Q34：向朋友介绍

**触发追问的条件：**
- 使用了专业术语 → 追问：「我说了不要用专业术语——就聊天，怎么跟一个完全不懂的朋友说」
- 描述过于简短（"我做xxx的"）→ 追问：「就这一句？你朋友会追问『具体做什么』——你怎么回答？」
- 描述变成了自我介绍（说了名字、头衔）→ 追问：「不要说你叫什么——说你做什么事」

**追问方向：**
- 「这段话是你说的原话吗？还是你为了听众改编过的？」
- 「这段话和你平时写的东西像吗？」

### Q35：最常出现的信息类型

**触发追问的条件：**
- 说"什么都用" → 追问：「不，一定有一种是你不自觉就带的。想想你写完一段回头看——最先注意到的是什么？」
- 说"故事"但 D1 的回答全是观点 → 追问：「你说你最常带的是故事，但你在 D1 里说的全是观点——哪个是真的你？」
- 无法举例 → 追问：「最近写的一段/说的一段话——里面主要是什么类型的信息？」

### Q36：刻意不带的内容

**触发追问的条件：**
- 说"没什么刻意不带" → 追问：「一定有的。有没有一种内容类型你看到别人写但你永远不会写的？」
- 理由过于通用（"太低级了"）→ 追问：「为什么它让你觉得低级？它触碰了什么？」
- 说"怕被judge" → 追问：「你怕谁judge你？为什么他们的看法重要？」

### Q37：默认节奏

**触发追问的条件：**
- 说"看情况" → 追问：「有默认模式——即使看情况，你 70% 的情况是什么节奏？」
- 说"快速抛出多个观点"但 D1 的回答全是深入论述 → 追问：「你说你节奏是快速多观点，但你的信念回答都很深入——矛盾吗？」
- 无法举例 → 追问：「最近的一段表达——开了几个头？每个头有多深？」

### Q38：自然 gravitate 的形式

**触发追问的条件：**
- 说"我都行" → 追问：「不——如果没有任何限制，你拿起什么最自然？」
- 说是"视频"但实际产出全是文字 → 追问：「你说 gravitate 视频，但你所有的作品都是文字——哪个是真实的你？」
- 说"我最擅长的" → 追问：「gravitate 不是擅长——是你不自觉就会去做的。不一样。」

### Q39：眼睛发亮的表达形式

**触发追问的条件：**
- 说是自己的领域 → 追问：「你自己的领域不算——我说的是别的领域」
- 说"没什么" → 追问：「一定有的——有没有一种表达形式你看了一眼就觉得『哇』？」
- 无法具体描述 → 追问：「能不能给我一个具体的例子——谁、做了什么、你看到了什么？」

### Q40：文字 vs 口头

**触发追问的条件：**
- 说"差不多" → 追问：「真的吗？有没有一个你在文字里永远不会说但在口头会说的话？」
- 说"文字更接近"但 Q34 的回答是口头风格 → 追问：「你说文字更接近真实的你，但你在 Q34 里描述的是一个聊天场景——那是什么？」

### Q41：最"卡"的形式

**触发追问的条件：**
- 说"都不卡" → 追问：「不可能——一定有一种形式你脑子里有东西但说不出来」
- 说"视频"但不做视频 → 追问：「你说视频卡——但你有试过认真做吗？还是只是觉得难？」
- 理由过于表面 → 追问：「为什么这种形式卡你？它触发了你什么？」

### Q42：从未尝试但想试的

**触发追问的条件：**
- 说"没什么想试的" → 追问：「真的？如果时间和钱都不是问题呢？」
- 说"视频"但 Q38 说 gravitate 写作 → 追问：「这和 Q38 的答案相反——你 gravitate 写作但最想试视频？为什么？」

### Q43：口头禅

**触发追问的条件：**
- 说"没什么特别的" → 追问：「你朋友一定说过——『你每次说话都会xxx』。想想看」
- 说是引用他人 → 追问：「那是别人的——你自己的呢？不是引用的」
- 只有 1-2 个 → 追问：「强迫自己列 5 个——先不筛选」

### Q44：内化的框架

**触发追问的条件：**
- 说"没什么" → 追问：「一定有的——你分析问题时用的某个框架，是你从某个老师或某本书学来的？」
- 框架过于通用 → 追问：「这个框架在什么场景下你会不自觉用上？」
- 说"都是自己想出来的" → 追问：「真的完全原创？没有任何源头？」

### Q45：永远不会用的词

**触发追问的条件：**
- 说"没什么" → 追问：「一定有的——比如『赋能』？『底层逻辑』？『闭环』？」
- 说"都行" → 追问：「不——一定有让你一看到就生理不适的词」
- 理由过于理性 → 追问：「为什么这个词让你不适？你的身体有什么反应？」

### Q46：开始表达的方式

**触发追问的条件：**
- 说"看情况" → 追问：「有默认方式——70% 的情况下你怎么开头？」
- 说"直接说观点"但 Q35 说最常带的是故事 → 追问：「你说最常带的是故事，但开头是直接说观点——怎么衔接的？」

### Q47：结束表达的方式

**触发追问的条件：**
- 说"看情况" → 追问：「默认方式——60% 的情况下你怎么收尾？」
- 说"总结升华"但 Q35 说最常带的是提问 → 追问：「你说最常带提问，但结尾是总结——这两个怎么配合？」

### Q48：语法/句式偏好

**触发追问的条件：**
- 说"没什么特别的" → 追问：「你写的东西和别人的放在一起，别人能认出来是你的吗？怎么认出来的？」
- 只提到标点符号 → 追问：「不只是标点——句子的长度呢？段落呢？你喜欢一段说透还是一段一个点？」
- 说"我写得很好" → 追问：「不是好不好——是『像不像你』。有没有一种句式，别人模仿了也不像你？」
