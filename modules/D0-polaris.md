## 板块说明

D0 是系统的入口和语境底座。所有后续板块都建立在 D0 建立的身份语境之上。

**这一板块在挖什么：**
你佩服谁 → 他们佩服谁 → 更深层的启发源；你在哪个领域探索；你是谁、代表什么、想以什么闻名；Ikigai 交叉点。

**为什么 D0 不能拆：**
D0 建立了被访谈者的"坐标系"。没有这个坐标系，后续板块中的信念、表达方式、禁区都无法被正确解读——同样的回答在不同身份语境下意味着完全不同的事。

## 问题列表

### Q1-Q6：北极星溯源

**Q1.** 你最欣赏的 3 位表达者或思想家是谁？不要想"最有名的"，想"最触动你的"——他们做了什么让你无法移开目光？

**Q2.** 选其中一位，讲一个具体的故事或时刻——他们的某段表达曾让你停下来，反复看了好几遍。是什么触动了你？

**Q3.** 这 3 位表达者/思想家各自有什么共同点？他们共享了什么品质、方法论或立场？

**Q4.** 这 3 位表达者/思想家各自的灵感来源是什么？他们推崇谁、受谁影响？去追踪他们的北极星。

**Q5.** 继续追踪：那些启发他们的人，又受谁影响？越深越好——你会在第三层或第四层找到属于自己的原始素材。

**Q6.** 从整个溯源链条中，哪个名字让你最意外？哪个启发源离你最远，却感觉最像你？

### Q7-Q12：领域定位

**Q7.** 你主要在哪个领域探索和表达？你如何定义这个领域——不是它的官方定义，而是你心里的那个版本？

**Q8.** 这个领域里最大的空白或最被忽视的问题是什么？你看到了什么别人没看到的东西？

**Q9.** 如果你只能向一个完全不了解你领域的人，用三句话介绍你在做什么——你会怎么说？

**Q10.** 你在表达中代表谁？你为谁发声，或者你在与谁对话？

**Q11.** 你希望人们如何描述你的表达方式？用三个动词和三个形容词。

**Q12.** 你最不希望别人如何描述你的表达方式？为什么？

### Q13-Q18：身份定位

**Q13.** 完整描述你的表达定位：通过 ______（你的服务/内容形式）交付 ______（核心价值）帮助 ______（你的受众）实现 ______（他们渴望的改变）。

**Q14.** 用一句话定义你是谁——不是你的职业头衔，而是你的本质。如果所有外在标签都消失，剩下的那个"你"是什么？

**Q15.** 用一段话扩展这句话——你的故事如何塑造了你的表达方式？哪些经历是你表达中不可分割的一部分？

**Q16.** 你最想让后人记住你的什么？不是墓碑上的字，而是人们提到你时最先想到的那个特质。

**Q17.** 如果把你所有的表达作品放在一起，它们之间最不可分割的共同线索是什么？

**Q18.** Ikigai 交叉点：你热爱什么 × 你擅长什么 × 世界需要什么 × 你能从中获得什么？这四个圆的交集在哪里？

### 知识考古可选追问（18 题之后）

以下 3 道题是 D0 的知识考古增强追问，**仅在用户完成 Q1-Q6 的溯源链条后、且用户表现出继续探索的兴趣时才触发**。它们不在 18 题的必答范围内，是追问扩展。

**Q-A1. 影响图谱检验**

> 回顾你刚才追踪到的整条影响链。有没有一个名字，在不同人物的故事里反复出现？
> 如果有——这个"共同出现"本身可能就是信号。你想进一步了解这个交汇点吗？

> **触发条件：** 用户在 Q4-Q5 中追踪了 2 层以上，且两条链出现了共同名字。
> **追问方向：** 如果用户说"想了解"，激活完整知识考古能力（见 `modules/north-star-exploration.md`）。

**Q-A2. 素材分层检验**

> 在你追踪到的这些人中，你分别从他们身上拿走了什么？
> 有些东西是**形式的**（怎么写、怎么表达），有些是**方法的**（怎么思考、怎么研究），有些是**原典的**（他们读的书、受的影响）。
> 你追踪到的这些东西，分别属于哪一层？

> **触发条件：** 用户在 Q4-Q5 中提到了具体的人物和作品。
> **追问方向：** 帮助用户区分"我想学他的风格"和"我想学他用的原材料"。

**Q-A3. 下一步探索**

> 基于你现在追踪到的这条链，你觉得下一步最值得探索的是什么？
> 是继续向上追溯——找到这个人的思想源头？
> 还是横向扩展——找到同时期的其他思考者？
> 还是回到你自己——用这些新发现重新审视你已经在做的事情？

> **触发条件：** 用户在 Q4-Q5 中产出了至少 2 层的影响链，且知识考古模式即将关闭。
> **追问方向：** 帮助用户决定下一步的学习方向，而不是无限追溯。

## 追问规则

### Q1：最欣赏的 3 位表达者

**触发追问的条件：**
- 回答是"最有名的"而非"最触动的" → 追问：「我说的不是最有名的，是最触动你的——那种让你觉得『这就是我想要的』的人」
- 只给 1-2 位而非 3 位 → 追问：「第三位呢？强迫自己多找一个」
- 给出的名字领域高度集中 → 追问：「这三位好像都在同一个领域——有没有一个完全不同领域的？」
- 回答以"他们都"开头（泛化） → 追问：「他们各自不同在哪？每个人最独特的是什么？」

**追问方向：**
- 「为什么是这三位而不是其他人？」
- 「他们各自触动了你不同的部分吗？」
- 「如果只能带一位到荒岛上，你会选谁？为什么？」

### Q2：具体故事

**触发追问的条件：**
- 回答过于笼统（"他的演讲很精彩"）→ 追问：「具体哪个时刻？哪个句子？当时你在做什么？」
- 没有个人情感投射 → 追问：「那让你想起了你自己什么？」
- 只描述了内容而非感受 → 追问：「你的身体有什么反应？有没有起鸡皮疙瘩？当时周围环境是什么样的？」

**追问方向：**
- 「那一刻你为什么会停下来？」
- 「这段话在你心里留下了什么？」
- 「如果把它翻译成你自己的表达，你会怎么说？」

### Q3：共同点

**触发追问的条件：**
- 回答过于泛化（"他们都很有深度"）→ 追问：「深度有很多种——是思想的深度？情感深度？还是……？」
- 只列出表面特征 → 追问：「这些特征背后更深层的是什么？」
- 说"没什么共同点" → 追问：「那你能被他们同时触动，说明什么？」

### Q4：灵感来源

**触发追问的条件：**
- 说"不知道" → 追问：「想想看——如果你要模仿他们，你会去哪里找源头？」
- 只给 1-2 层深度 → 追问：「再往深挖一层——那些人又受谁影响？」

### Q5：第三层第四层

**触发追问的条件：**
- 停在第一层 → 追问：「他们的灵感来源是谁？再往下一层」
- 觉得无聊 → 追问：「别急——第四层那个名字通常会出人意料」

**追问方向：**
- 「那个让你最意外的名字是什么？为什么？」
- 「那个最远的启发源，怎么感觉最像你？」

### Q6：最意外的名字

**触发追问的条件：**
- 没有"意外"的感觉 → 追问：「那链条里哪个名字离你最远？按直觉选一个」
- 说不清楚为什么 → 追问：「你不用解释——有时候直觉比解释更准」

### Q7：领域定义

**触发追问的条件：**
- 使用了官方/教科书定义 → 追问：「那是对外的定义。你心里的那个版本呢？」
- 定义过于宽泛（"我什么都做"）→ 追问：「如果必须缩小到你能用一句话说清的范围呢？」
- 把领域定义为"我正在学的" → 追问：「你学习它，和你表达它，是同一件事吗？」

### Q8：最大的空白

**触发追问的条件：**
- 说"没有空白"或"都有人做了" → 追问：「那为什么你还在做？一定有什么别人没看到的」
- 只提到技术层面 → 追问：「不是技术空白——是视角的空白。你看到了什么别人没看到的？」
- 回答变成了批评他人 → 不阻止，但追问：「那你呢？你在填补什么？」

### Q9：三句话介绍

**触发追问的条件：**
- 用术语或行话 → 追问：「我说了完全不了解你领域的人——用你外婆能听懂的话」
- 超过三句话 → 追问：「压缩到三句——最精简的版本」
- 变成了自我介绍（"我叫 xxx，我做了…"）→ 追问：「不要说你做了什么，说你在解决什么」

**追问方向：**
- 「这三句话里，哪句最重要？」
- 「如果只能留一句，你留哪句？」

### Q10：为谁发声

**触发追问的条件：**
- 说"所有人" → 追问：「所有人是你最真实的受众吗？还是你不确定是谁所以选了最大公约数？」
- 说"像我一样的人" → 追问：「像你哪方面？哪个阶段的你？」
- 没有情感投入 → 追问：「想象你在和一个具体的人对话——他/她坐在你对面，你想对他说什么？」

### Q11：三个动词 + 三个形容词

**触发追问的条件：**
- 用陈词滥调（"创新的、专业的、高效的"）→ 追问：「这些词太安全了——如果你是说给你最信任的朋友听呢？」
- 动词和形容词不匹配 → 追问：「你说你的表达是『犀利的』但动词是『陪伴』——这两个好像有点冲突？」
- 少于 3 个 → 追问：「强迫自己各给三个——先不筛选，所有跑出来的都算」

### Q12：最不希望被描述的方式

**触发追问的条件：**
- 说"没什么不希望的" → 追问：「一定有的——哪怕是很小的事。比如『装』？『刻意』？『无聊』？」
- 只给形容词不给原因 → 追问：「为什么这个词让你不舒服？它触碰了什么？」
- 说了一个词但没有情绪反应 → 追问：「再想想——哪个词会让你如果听到别人这么形容你，你会心里一紧？」

### Q13：完整定位陈述

**触发追问的条件：**
- 任何一个空填不上 → 追问：「没关系，空着也没关系——但空着说明那里有值得探索的东西」
- "服务/内容形式"过于笼统（"我发内容"）→ 追问：「具体的形式——长文？对话？视频？音频？」
- "受众"过于宽泛（"所有人"）→ 追问：「最想触动的那个具体的人是什么样的？」
- "核心价值"变成了功能描述 → 追问：「不是你能做什么，是你带来的改变是什么？」

**追问方向：**
- 「如果把这个句子中的任何一个空换成别人的答案，那个人是谁？」
- 「这句话读起来让你有感觉吗？还是只是一个模板？」

### Q14：一句话定义自己

**触发追问的条件：**
- 用了职业头衔 → 追问：「去掉头衔——如果没有人知道你是做什么的，你是谁？」
- 说了一个特质但无法展开 → 追问：「这个特质在你的生活里具体表现为什么？」
- 说"不知道" → 追问：「如果你最好的朋友被问到这个问题，他会怎么替你回答？」

### Q15：故事如何塑造表达

**触发追问的条件：**
- 说"没什么特别的经历" → 追问：「真的吗？有没有一个时刻你觉得『从那时候起我变了』？」
- 只提到童年 → 追问：「最近的呢？有没有一个近期的经历改变了你怎么表达？」
- 回答变成了简历 → 追问：「不是时间线——是哪些经历变成了你表达里的『肌肉记忆』？」

### Q16：最想让后人记住的

**触发追问的条件：**
- 说"不知道" → 追问：「不用想墓碑——想象你在一个聚会上，大家提到你，第一个冒出来的词是什么？」
- 回答过于功利（"我的作品"）→ 追问：「作品背后是什么？那个特质是什么？」
- 和 Q14 的回答完全一样 → 追问：「你刚才说的『本质』和这里说的『后人记住的特质』是同一个东西吗？」

### Q17：共同线索

**触发追问的条件：**
- 说"没什么共同线索" → 追问：「真的吗？那为什么这些作品都是你写的而不是别人？」
- 只提到主题层面 → 追问：「不止主题——句式呢？节奏呢？开场方式呢？」
- 提到风格但无法举例 → 追问：「能不能举一个具体的例子？」

### Q18：Ikigai 交叉点

**触发追问的条件：**
- 四个圆没有交集 → 追问：「没关系，交集不在现在——你在往哪个方向移动？」
- 交集过于完美 → 追问：「真的吗？如果诚实地看，哪个圆最小？哪个最大？」
- 只提到"热爱"和"擅长" → 追问：「世界需要什么？你能从中获得什么？这两个圆往往是最容易被忽略的」

**追问方向：**
- 「这个交集有没有一个具体的画面？」
- 「你现在的生活离这个交集有多远？」

## 跨题追问规则（扩展层）

以下 5 条规则贯穿 D0 全程，在检测到对应信号时自动触发。它们是 D0 追问规则的扩展层，不替代上述逐题规则。

---

### 规则1：四级共振检测追问

**目的：** 区分"佩服"、"认出"、"认同"、"方向"四个层级，追踪用户对表达者的真实共振深度。

**触发条件：** 任何一道题的回答中出现以下信号词时：

| 用户表述 | 检测层级 | 系统追问 |
|---|---|---|
| "他很厉害"、"很优秀" | Admiration | "厉害有很多种——你想成为他什么？" |
| "他说出了我想说的话"、"我一直这么觉得" | Recognition | "具体是哪句话？为什么这句话让你有这种感觉？" |
| "这就是我"、"我就是这样的人" | Identification | "具体在哪些方面？有没有一个时刻你觉得'对，这就是我'？" |
| "我愿意…十年"、"一辈子"、"一直" | Direction | "十年后你想成为什么？如果这条路和别人完全不同，你还会走吗？" |

**共振升级规则：**
- 同一个候选人物可以在不同题目中逐步升级共振层级
- 升级不可逆——标记为 Identification 后不会降回 Recognition
- 达到 Direction 层级后，记录到 `candidateNorthStar`，在板块结束时触发压力测试

**详细规范：** 见 `modules/north-star-exploration.md`

---

### 规则2：追溯式追问（知识考古触发）

**目的：** 当用户提到某个人物时，自动触发追溯追问，激活知识考古能力，构建影响图谱。

**触发条件：** 用户答案中包含以下信号时：

| 信号 | 典型表述 | 激活的追溯轮次 |
|---|---|---|
| 人物提及 | "A 影响了我的看法"、"A 的观点让我…" | 第一层追溯 |
| 灵感来源 | "他受谁影响"、"他的来源是…" | 第一至二层追溯 |
| 共同引用 | "他也提到了…"、"他们都引用了…" | 第三层（交汇点检测） |

**追问模板：**

```
"你说 A 影响了你。A 在公开场合提到过哪些影响他的人？
有没有一本书、一个理论、或另一个人，是 A 反复引用的？"

"那 B（A 的来源）呢？B 的思想从哪里来？
B 受谁影响？B 的『北极星』是谁？"

"你现在追踪到的几条链——A→B 和 A→C
有没有一个名字，同时出现在两条链上？"
```

**追溯约束：**
- 最多追溯 3 层，超过后暂停并询问用户"要继续追还是先回到主线？"
- 每层追溯后必须同步执行规则3（剥离式追问）
- 追踪到 3 层后自动退出知识考古模式，回到 D0 主线

**详细规范：** 见 `modules/north-star-exploration.md`

**触发 D0 题目：** Q1、Q2、Q4、Q5、Q6（这些题目天然涉及人物追溯）

### 规则3：剥离式追问

**目的：** 把人物从答案中剥离，提取原则。防止用户陷入"模仿他人"而非"发现自己的原则"。

**触发条件：** 用户的答案包含人物名字时，在以下时机自动触发：

| 时机 | 触发条件 | 追问 |
|---|---|---|
| 任何含人物的回答后 | 答案中提到至少一个人物名字 | "如果这个人不存在了，你真正想留下的是什么？" |
| 知识考古追溯后 | 每完成一层追溯 | "把 A 的名字从你的答案里去掉，剩下的那句话说的是谁？" |
| 北极星候选形成后 | 用户给出了以人物为中心的方向描述 | "想象 A 从来没有存在过——没有他的文章、产品、演讲。你身上已经有的东西里，什么让你被 A 吸引？" |

**追问模板：**

```
"把 [人物名] 从你的答案里去掉。
剩下的那句话，说的是谁？"

"如果 [人物名] 的所有外在成就都被抹掉，
只剩下他对待世界的方式——
那个方式可以用一句话描述吗？"

"你说你想成为 [人物名]。
但如果 [人物名] 这个人本身不存在，
你真正想留下的是什么？"
```

**剥离检验标准：** 用户给出的去人名化描述，应该让一个完全不认识这些人物的人也能理解。

**关键原则：** 剥离不是否定人物的价值，而是帮用户发现——**"你追的不是这个人，是这个人身上呈现出来的某种可能性。那种可能性才是你的北极星。"**

### 规则4：压力测试追问

**目的：** 在检测到候选北极星时，自动触发五项压力测试，检验候选方向的稳定性。

**触发条件：** 当以下任一信号出现时：

| 触发信号 | 检测时机 |
|---|---|
| 共振检测达到 Direction 层级 | 在板块结束时自动触发 |
| 用户给出了去人名化的北极星候选陈述 | 在 Q13、Q14、Q16 后触发 |
| 知识考古产出了明确的共振点 | 在板块结束时自动触发 |
| 用户显式说"我觉得这就是我的方向" | 立即触发 |

**五项检验：**

```
① 没有观众，你还做吗？
   如果答案是"不" → 可能是社会认同，而非北极星

② 没有钱，你还做吗？
   如果答案是"不" → 可能主要是商业目标

③ 没有人知道，你还做吗？
   如果答案是"不" → 可能主要是身份表演

④ 没有现成模板，你还会探索吗？
   如果答案是"是" → 开始接近内在驱动

⑤ 十年后仍然如此，你愿意吗？
   如果答案是"是" → 可能已经非常接近北极星
```

**追问方式：** 一次只问一个，不要一次性抛 5 个问题。从①开始逐问。

**结果处理：**
- 全部通过 → 标记候选北极星为"压力测试通过"，进入 Round 9 确认
- 有 1-2 项不确定 → 标记为"待验证"，在核心模式中追加追问
- 有 3 项以上失败 → 返回 Round 6 重新收敛候选方向

**详细规范：** 见 `modules/north-star-exploration.md`（压力测试 / Round 8）

### 规则5：重复检测追问

**目的：** 在 D0 全程追踪高频出现的词汇和概念，发现用户自己可能没意识到的模式。

**触发条件：** 系统在 D0 全程维护一个**高频词计数器**，当以下任一条件满足时触发：

| 条件 | 追问 |
|---|---|
| 同一词汇/概念出现 3 次以上 | "你反复提到『[词汇]』——这个词对你来说具体意味着什么？" |
| 两个概念同时出现在不同题目中 | "你在 Q1 提到了『探索』，在 Q18 也提到了『探索』——这两个『探索』是同一个意思吗？" |
| 概念与用户的禁区描述矛盾 | "你说你最不希望被描述为『刻意』，但你 Q1 提到的所有人都非常刻意——这之间有张力" |

**高频词追踪规则：**
- 精确匹配：同一词汇出现 3 次以上
- 语义匹配：不同词汇但表达同一概念（如"自由"和"自主"）出现 3 次以上
- 不计功能词（"做"、"想"、"觉得"等）
- 不计否定词（"不"、"不是"等）

**追问原则：**
- 不是质问（"你为什么反复说这个词？"），而是好奇（"我注意到你反复提到这个词——它对你来说意味着什么？"）
- 一次只追问一个高频词，不堆叠
- 如果用户解释了高频词，追加到 `coreIdentity` 候选词库

**与张力检测的联动：**
- 高频词与 Q12（最不希望被描述的方式）矛盾时，自动记录为张力
- 高频词出现在多个影响链中时，标记为**共振点信号**——可能是北极星的方向

## 北极星溯源逻辑

Q1-Q6 构成一个溯源链条。这个链条的目的是帮助被访谈者找到自己表达的"原始素材"——那些深层影响你的、你可能自己都没意识到的启发源。

**溯源深度指导：**
- Q1：表层（你知道你欣赏谁）
- Q2-Q3：第二层（为什么是他们）
- Q4-Q5：第三至四层（他们受谁影响）
- Q6：深层（那个意外的名字 = 你自己的隐藏影响源）

**关键原则：**
溯源的目的不是学术研究，是帮助被访谈者发现自己的"原始素材"——那些你表达中反复出现的元素，可能来自一个你从未直接学习过的启发源。
