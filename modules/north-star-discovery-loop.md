# 北极星发现循环（North Star Discovery Loop）

> 北极星不是你最崇拜的人，而是在你长期的欣赏、学习、追溯和实践中反复出现的一种方向感。更锋利地说：**北极星，是你在别人身上反复认出的自己。**

北极星发现循环是 D0 板块的**深层算法**。它把 18 道题的问答转化为一个从"外部模仿对象"到"内部稳定方向"的收敛过程。

---

## 1. 循环总览

```
Round 1  捕捉：谁让你产生"我也想成为这样的人"？
    ↓
Round 2  具体化：到底是什么让你想成为他？
    ↓
Round 3  剥离人物：如果这个人不存在，你真正想留下的是什么？
    ↓
Round 4  追溯来源：他受谁影响？那些人又受谁影响？
    ↓
Round 5  提取属性：把人物 → 行为 → 品质 → 原则 → 人生方向
    ↓
Round 6  去人名化：删除所有人物名字，形成3-5个候选方向
    ↓
Round 7  过去验证：你过去是否自发做过与此一致的事？
    ↓
Round 8  未来压力测试：十年无回报还愿意吗？
    ↓
         ★ 北极星
```

**关键设计：** 这个循环不是线性的。Round 4（追溯）与知识考古能力衔接，Round 3（剥离）在每轮追溯中都必须同步执行。循环可以在任意轮次暂停，从任意轮次继续。

---

## 2. 各轮详细设计

### Round 1：捕捉（Capture）

**核心问题：** 谁让你产生过强烈的"我也想成为这样的人"的感觉？

**不是**"谁最厉害"，而是"谁让你产生身份欲望"。

**触发问题：** Q1（最欣赏的 3 位表达者）

**追问逻辑：**

```
如果用户说"我很佩服 xxx" → 追问："佩服和想成为不一样——你想成为他什么？"
如果用户说"他的文章写得很好" → 追问："不只是文章——他这个人本身有什么让你向往的？"
如果用户说"不知道" → 追问："想想看——有没有一个人，如果你拥有了他的某些特质，
                                  你的生活会完全不同？"
```

**输出：** 3-5 个候选人物，每人附带一句话描述"你想成为他的什么"。

**共振标记：** 对每个候选人物，标记初步共振层级（admiration / recognition / identification / direction）。

---

### Round 2：具体化（Specify）

**核心问题：** 到底是什么让你想成为他？

逼用户从"我喜欢 Naval"变成"我喜欢他对财富、自由、知识和人生的处理方式"。

**触发问题：** Q2（具体故事/时刻）→ 延伸追问

**追问逻辑：**

```
"你说你喜欢 A。但'喜欢'这个词太宽了。
具体是什么？是 A 做事情的方式？
是 A 看待问题的方式？
是 A 对待人的方式？
还是 A 创造的东西本身？"

"如果 A 的所有作品都被删掉了，但你保留了一个特质——
那个特质是什么？"
```

**输出：** 每个候选人物的"具体化描述"——不是"我喜欢他"，而是"我向往他身上的 X、Y、Z"。

**共振升级检测：** 如果用户能说出具体的行为/品质而非笼统的"厉害"，标记为 recognition 层级。

---

### Round 3：剥离人物（Strip the Person）

**核心问题：** 如果这个人不存在了，你真正想留下的是什么？

这是整个循环中最关键的一步。它将 **Person** 剥离成 **Principle**。

**触发问题：** Q2-Q6 的延伸追问 / 在任何提及人物的回答后自动触发

**追问逻辑：**

```
"想象 A 从来没有存在过——没有他的文章、产品、演讲。
你身上已经有的东西里，什么让你被 A 吸引？
A 只是唤醒了你本来就有的东西。"

"如果 A 的所有外在成就都被抹掉，
只剩下他对待世界的方式——
那个方式可以用一句话描述吗？"

"把 A 的名字从你的答案里去掉。
剩下的那句话，说的是谁？"
```

**输出：** 每条影响链的"去人名化"原则。

**示例转化：**

```
输入：  "我想成为 Naval——独立思考、创造财富、追求自由。"
剥离：  "如果 Naval 不存在，我想留下的是：
         独立思考 + 自主创造价值 + 自由探索。"
去人名："我希望自己成为一个可以独立思考、
        自主创造价值、自由探索的人。"
```

**共振升级检测：** 如果用户能脱离人物描述原则，标记为 identification 层级。

---

### Round 4：追溯来源（Trace Back）

**核心问题：** 他受谁影响？那些人又受谁影响？

这轮与**知识考古能力**直接衔接。系统自动激活追溯追问，构建影响图谱。

**触发问题：** Q4-Q5（灵感来源追踪）

**执行方式：** 激活知识考古模式，最多追溯 3 层，产出影响图谱。

**追问逻辑：**
（由知识考古能力接管，见 knowledge-archeology.md）

**关键约束：**
- 每追溯一层，必须同步执行 Round 3 的剥离追问
- 追踪到 3 层后暂停，问用户"要继续追还是回到主线？"
- 标记图谱中的共振节点

**输出：** 结构化的影响图谱（最多 4 层深度，包含人物、书籍、理论、传统）

---

### Round 5：提取属性（Extract Attributes）

**核心问题：** 从影响链中提取你反复追求的核心属性。

转换路径：人物 → 行为 → 品质 → 原则 → 人生方向

**触发条件：** Round 4 的影响图谱完成后

**追问逻辑：**

```
"回顾你追踪到的整条影响链——
有没有一个品质或原则，在每一层都出现了？

比如：Naval → Taleb → Montaigne
  Naval 的：独立创造
  Taleb 的：反脆弱
  Montaigne 的：自由探索
  
  共同点是什么？"

"你的影响链里，有没有一个词或概念，
在不同的人物身上反复出现，但表达方式不同？

这个概念就是你的核心属性。"
```

**提取方法：**

1. 列出影响链上每个节点的核心品质
2. 找出跨节点重复出现的品质
3. 将重复品质抽象为 3-5 个"候选方向"
4. 每个候选方向用一句话描述（不用人物名）

**输出：** 3-5 个候选人生方向（去人名化）

---

### Round 6：去人名化（De-personalize）

**核心问题：** 删除所有人物名字，形成 3-5 个候选方向。

这一步的检验标准是：**一个完全不认识这些人物的人，能不能理解你的候选方向？**

**触发条件：** Round 5 完成后

**追问逻辑：**

```
"把你刚才说的所有候选人名都删掉。
'我希望成为一个像 Naval 那样独立思考的人' →
'我希望成为一个独立思考的人。'

现在你有 3-5 个方向。
如果只能选 2 个，你选哪两个？
如果只能选 1 个，你选哪个？"
```

**收敛规则：**
- 从 3-5 个候选方向中，用户必须选择一个"核心方向"
- 不强迫——如果用户觉得 2 个方向同等重要，允许保留，标记为"双核"
- 核心方向用一句话描述，不包含任何人名

**输出：** 1-2 个候选北极星陈述（去人名化）

**共振升级检测：** 当用户读到去人名化的陈述后，如果产生"是，就是这个"的感觉，标记为 direction 层级。

---

### Round 7：过去验证（Past Evidence）

**核心问题：** 你过去是否自发地反复做过与这个方向一致的事？

北极星不是兴趣，是**反复出现的自发行为**。

**触发条件：** Round 6 产出候选北极星陈述后

**追问逻辑：**

```
"你刚才说你的方向是『通过持续创造来理解世界』。
回顾过去 3-5 年——

你有没有自发地反复做过与此一致的事？
哪怕没有回报、没有人看、没有任何外部激励？

举个例子。"
```

**验证维度：**

| 维度 | 问题 | 检验什么 |
|---|---|---|
| 频率 | 过去几年做过几次？ | 不是一次冲动，是反复出现 |
| 自发 | 有没有外部要求或激励？ | 内在驱动，不是外部压力 |
| 一致性 | 方向是否始终如一？ | 不是一时兴起，是稳定模式 |
| 代价 | 为此放弃过什么？ | 愿意付出代价，说明是真的 |

**输出：** 2-3 个过去行为的证据案例

---

### Round 8：未来压力测试（Future Stress Test）

**核心问题：** 如果十年没有明显回报，你还愿意朝这个方向走吗？

**触发条件：** Round 7 验证通过后

**追问逻辑：**

```
"想象一下——十年后，你在这条方向上走了很远，
但还没有取得世俗意义上的『成功』——
没有大量观众、没有商业回报、没有社会认可。

你还会继续吗？

再具体一点：
- 如果没有观众，你还创作吗？
- 如果没有钱，你还研究吗？
- 没有人知道你在这条路上，你还在走吗？
- 如果必须放弃现在的一些东西（稳定工作、社交形象），你愿意吗？
"
```

**五项检验：**

| 检验 | 问题 | 排除什么 | 通过标准 |
|---|---|---|---|
| ① 无观众 | 没有观众还做吗？ | 社会认同 | 是 |
| ② 无回报 | 没有钱还做吗？ | 商业目标 | 是 |
| ③ 无名 | 没有人知道还做吗？ | 身份表演 | 是 |
| ④ 无模板 | 没有现成路径还探索吗？ | 消费知识 | 是 |
| ⑤ 十年 | 十年无回报还愿意吗？ | 一时兴趣 | 是 |

**输出：** 五项检验的结果。任何一项为"否"或"不确定"，返回 Round 6 重新收敛候选方向。

---

### Round 9：收敛与确认（Converge）

**核心问题：** 这就是你的北极星了吗？

**触发条件：** Round 8 五项检验全部通过后

**追问逻辑：**

```
"现在你有：
- 3-5 个候选北极星方向（去人名化）
- 2-3 个过去行为的验证证据
- 五项压力测试全部通过

系统从你的回答中推导出：

[北极星陈述草稿]

这句话让你产生多强的『是，就是这个』的感觉？

1. 完全不是——这不是我
2. 有点像——但不完全是
3. 基本是——但我可以微调几个词
4. 是——这就是我
```

**用户反馈处理：**

| 反馈 | 系统动作 |
|---|---|
| 1（完全不是） | 返回 Round 6，重新收敛候选方向 |
| 2（有点像） | 追问"哪个词不对？你想怎么改？" |
| 3（基本是） | 根据用户的微调修改陈述，再问一次 |
| 4（是） | 确认北极星，标记为最终版本 |

**输出：** 最终的北极星陈述（一句话）+ 北极星卡片（见第 3 节）

## 3. 北极星卡片输出

循环完成后，产出一张**北极星卡片**——不是一句话，而是一个多维度的自我描述。

### 卡片结构

```markdown
## 我的北极星

### 核心方向
> [一句话，去人名化，不包含任何他人名字]

### 我被什么人吸引
> [列出影响链上产生共振的人物，标注共振层级]
> 一阶：[名字]（方向级共振）
> 二阶：[名字]（认同级共振）
> 三阶：[名字]（认出级共振）

### 我反复追求的属性
> [3-5 个从影响链中提取的核心属性]
> 1. [属性]
> 2. [属性]
> 3. [属性]

### 我不想成为
> [通过 Q12 的禁区题提取]
> [1-2 条明确的反方向]

### 过去的证据
> [2-3 个过去自发行为的案例]
> - [案例 1]
> - [案例 2]

### 未来投射
> [1-2 段关于未来方向的描述]

### 当前 90 天北极星
> [将人生方向转化为当前可执行的行动]
> [这个字段在每次自我表达审计的编译阶段更新]
```

## 4. 循环的特殊模式

### 快速循环（仅 Round 1 + Round 6）

在快速模式下，循环被压缩为两步：

1. **Round 1**：捕捉 3 个候选人物
2. **Round 6**：去人名化，形成 1-2 个候选方向

不执行 Round 2-5 的深度追问，也不执行 Round 7-8 的压力测试。

**快速循环的输出：** 候选方向陈述 + 升级邀请（建议完成核心模式以获取完整北极星）

### 中断恢复

如果用户在中途暂停，循环状态被保存到状态文件的 `northStarLoop` 字段：

```json
{
  "northStarLoop": {
    "currentRound": 4,
    "completedRounds": [1, 2, 3],
    "candidates": [...],
    "knowledgeGraph": {...},
    "resumeFrom": "Round 4: 追溯来源"
  }
}
```

恢复时，系统从 `currentRound` 继续，不需要重做已完成的部分。

## 5. 收敛算法

从多个候选方向收敛到一个北极星的算法：

### 步骤 1：频次统计

追踪 D0 全程中用户反复出现的词汇和概念。出现 3 次以上的词汇标记为**高频词**。

```
高频词标记规则：
- 精确匹配：同一词汇出现 3 次以上
- 语义匹配：不同词汇但表达同一概念（如"自由"和"自主"）出现 3 次以上
```

### 步骤 2：排除法

从候选方向中排除以下类型：

| 排除类型 | 检测方法 | 替代策略 |
|---|---|---|
| 社会认同 | 高频词中"被认可"、"出名"、"被看到"等 | 追问：如果没有人知道，你还愿意？ |
| 商业目标 | 高频词中"赚钱"、"成功"、"变现"等 | 追问：如果不需要赚钱，你还做什么？ |
| 身份表演 | 高频词中"看起来很"、"让别人觉得"等 | 追问：如果没有人知道你做了，你还做吗？ |
| 一时兴趣 | 高频词只出现 1-2 次，没有行为证据 | 等待 Round 7 验证 |

### 步骤 3：交叉验证

将候选方向与以下数据源交叉验证：

| 数据源 | 验证什么 |
|---|---|
| Q1 北极星溯源链 | 候选方向是否与影响链一致？ |
| Q7-Q12 领域定位 | 候选方向是否在定义的领域内？ |
| Q13 定位陈述 | 候选方向是否与定位陈述的核心价值一致？ |
| Q18 Ikigai | 候选方向是否在 Ikigai 交集附近？ |
| 张力日志 | 候选方向是否解决了某个张力？ |
| 知识图谱 | 候选方向是否有足够的素材支撑？ |

### 步骤 4：最终确认

如果多个候选方向都通过验证：
- 优先级排序：高频词最多的方向 > 最久远的自发行为支持的方向 > 压力测试中最坚定的方向
- 如果两个方向权重接近，标记为"双核北极星"，两者都保留
- 不允许超过 2 个核心方向——超过说明还没有收敛

## 6. 北极星的动态性

**北极星不是固定的。** 它会随着你的经历、学习和创作而演变。

### 演变规则

| 触发条件 | 系统行为 |
|---|---|
| 用户在后续对话中显式修改北极星 | 更新北极星卡片，记录变更时间 |
| 用户在 D1-D7 中表现出与当前北极星矛盾的行为 | 在张力日志中记录，在下次编译时提示 |
| 用户在北极星压力测试中的回答发生变化 | 更新北极星卡片，标记"已验证"→"待复核" |
| 30 天后用户重新启动审计 | 提示"你的北极星可能已经演变，要不要重新评估？" |

### 北极星的版本管理

每次北极星被确认或修改时，保存一个版本：

```json
{
  "northStarHistory": [
    {
      "version": 1,
      "date": "2026-08-19",
      "statement": "...",
      "context": "首次审计，核心模式",
      "evidence": ["Q13", "Q18", "Round 7"]
    },
    {
      "version": 2,
      "date": "2026-10-15",
      "statement": "...",
      "context": "30天后续审计",
      "evidence": ["Q1", "Q19", "Round 7"],
      "changeNote": "方向微调：从『创造来理解世界』到『通过探索来创造』"
    }
  ]
}
```

## 7. 与 D0 现有题目的映射

北极星发现循环不是新增问题，而是**重新解释了 D0 现有 18 题的深层目的**：

| D0 题号 | 表面目的 | 在发现循环中的角色 |
|---|---|---|
| Q1 | 最欣赏的 3 位表达者 | **Round 1 捕捉** — 输入候选人物 |
| Q2 | 具体故事 | **Round 2 具体化** — 深化每个候选 |
| Q3 | 共同点 | **Round 5 提取属性** — 提取跨候选的共性 |
| Q4 | 灵感来源 | **Round 4 追溯** — 第一层追溯 |
| Q5 | 第三层第四层 | **Round 4 追溯** — 第二至三层追溯 |
| Q6 | 最意外的名字 | **Round 4 追溯** — 共振点检测 |
| Q7 | 领域定义 | 语境底座 — 定义北极星发生的领域 |
| Q8 | 最大空白 | 语境底座 — 定义北极星解决的问题 |
| Q9 | 三句话介绍 | 语境底座 — 测试北极星的表达能力 |
| Q10 | 为谁发声 | 语境底座 — 定义北极星的受众 |
| Q11 | 三个动词+三个形容词 | 语境底座 — 北极星的表达特征 |
| Q12 | 最不希望被描述 | 语境底座 — 北极星的反面（不想成为） |
| Q13 | 完整定位陈述 | **Round 6 去人名化** — 北极星的初步表达 |
| Q14 | 一句话定义自己 | **Round 6 去人名化** — 北极星的简洁版本 |
| Q15 | 故事如何塑造表达 | **Round 7 过去验证** — 北极星的证据 |
