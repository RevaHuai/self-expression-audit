# 四级共振检测器（Resonance Detector）

> 当用户提到某个表达者、思想或作品时，系统自动检测用户的共振层级。不是"我喜欢他"，而是逐层递进：佩服 → 认出 → 认同 → 方向。

四级共振检测器贯穿 D0 全程，是北极星发现循环的核心检测机制。

---

## 1. 四级定义

### 第一级：Admiration（佩服）

**特征：** "这个人很厉害。"

- 用户关注的是人物的**成就、地位、能力**
- 回答以"他很…"开头（厉害、优秀、成功）
- 回答聚焦于**产出**（写了什么、做了什么、取得了什么）
- 没有个人情感投射

**示例回答：**
- "Naval 非常聪明，他把财富和自由的关系讲得很清楚。"
- "他的文章写得非常好，逻辑很严密。"

**不标记为北极星。** Admiration 是对外部成就的认可，不是对内在方向的认同。

**追问方向：** "他具体做了什么让你觉得厉害？厉害和你想成为他是两回事——你想成为他什么？"

---

### 第二级：Recognition（认出）

**特征：** "他说出了我一直想说、但没有说出来的东西。"

- 用户关注的是人物的**观点、洞察、表达**
- 回答以"他说出了…"或"我也一直觉得…"开头
- 回答聚焦于**思想的共鸣**而非人的成就
- 有个人情感投射——"这就是我想的"

**示例回答：**
- "他说出了我一直想说但说不清楚的话——关于财富不是金钱而是选择自由。"
- "他的观点让我觉得'哦，原来我想的没错'。"

**标记为潜在北极星信号。** Recognition 意味着用户在思想上与这个人物对齐，但还没有转化为自己的方向。

**追问方向：** "具体是哪句话？为什么这句话让你有这种感觉？如果这句话是你自己写的，你会怎么写？"

---

### 第三级：Identification（认同）

**特征：** "这就是我"——不是"我想成为他"，而是"他把某个本来就在我身上的东西显现出来了"。

- 用户关注的是人物的**存在方式、态度、生活方式**
- 回答以"我就是这样的人"或"这就是我的方式"开头
- 回答聚焦于**身份认同**而非外部成就或观点
- 有深层情感连接——"这不是我想成为的，这就是我"

**示例回答：**
- "他对待知识的方式——不是为了炫耀，是为了理解——这就是我。"
- "他做事情的那种节奏，不急不躁，长期主义——我就是这样的。"

**标记为强北极星信号。** Identification 意味着用户在身份层面与这个方向对齐。这是北极星发现的关键节点。

**追问方向：** "具体在哪些方面？有没有一个时刻你觉得'对，这就是我'？如果他没有做这些事，你会发现自己有这个特质吗？"

---

### 第四级：Direction（方向）

**特征：** "如果沿着这个方向继续走，我愿意走十年。"

- 用户关注的是人物的**人生方向、长期轨迹**
- 回答包含**时间承诺**（我愿意…、我打算…、我想…）
- 回答包含**长期性**（十年、一辈子、一直）
- 有明确的**未来投射**

**示例回答：**
- "如果沿着这条路走十年，我愿意。即使没有回报。"
- "我想把这种独立思考的方式变成我一辈子的习惯。"

**标记为确认北极星。** Direction 是四级共振的最高层级，只有达到这一级，才是一个真正的北极星。

**追问方向：** "十年后你想成为什么？如果这条路和别人推荐的路完全不同，你还会走吗？"

## 2. 检测规则

### 自动检测触发条件

系统在 D0 全程自动监听以下信号：

| 信号类型 | 检测关键词/模式 | 对应层级 |
|---|---|---|
| 成就导向 | "他很厉害"、"很成功"、"做得很棒" | Admiration |
| 观点共鸣 | "他说出了…"、"我也一直觉得…"、"这就是我想的" | Recognition |
| 身份认同 | "这就是我"、"我就是这样的人"、"这是我的方式" | Identification |
| 长期承诺 | "我愿意…十年"、"一辈子"、"一直"、"永远" | Direction |

### 标记和追踪

每次检测到共振信号时，系统记录：

```json
{
  "resonanceLog": [
    {
      "id": "R1",
      "timestamp": "Q2 回答时",
      "person": "Naval",
      "level": "recognition",
      "triggerPhrase": "他说出了我一直想说但说不清楚的话",
      "evidence": "Q2 回答中：'他关于财富自由的描述让我觉得这就是我一直在想的'",
      "upgraded": false
    }
  ]
}
```

### 共振升级检测

同一个候选人物可能在多次回答中逐步升级共振层级。系统追踪这种升级：

| 场景 | 升级动作 |
|---|---|
| Q1 说"他很厉害"（Admiration），Q2 说"他说出了我想说的话"（Recognition） | R1.level: admiration → recognition |
| Q2 说 Recognition，Q6 说"那个最远的启发源感觉最像我"（Identification） | R1.level: recognition → identification |
| Q18 说"我愿意这样走一辈子"（Direction） | R1.level: identification → direction |

**升级规则：**
- 升级不可逆——一旦标记为 Identification，不会降回 Recognition
- 升级时追加记录到 resonanceLog，保留原始记录
- 达到 Direction 层级后，触发北极星压力测试（Round 8）

## 3. 共振检测与知识考古的联动

当知识考古被激活时，四级共振检测同步执行：

### 第一层追溯时的共振检测

```
用户提到 A（Admiration）
系统追溯 A 的来源 B
用户对 B 的评价 → 检测 B 的共振层级

如果 B 的共振层级高于 A：
  "有趣——你对 B 的共鸣比对 A 更深。
   这说明什么？"
  → 这可能意味着 B 才是真正的共振点
```

### 共振点检测

在追溯过程中，如果某个节点（无论在第几层）的共振层级达到 Identification 或 Direction，系统标记为**共振点**：

```
共振点 ≠ 北极星
共振点 = "在影响链上让我产生强烈身份共鸣的节点"
```

**共振点与北极星的关系：**
- 共振点可能是北极星本身
- 共振点可能指向北极星的来源
- 多个共振点可能指向同一个北极星方向

**处理方式：** 标记所有共振点，在 Round 6（去人名化）时一起处理。

## 4. 共振检测与原型锚点的联动

### 锚点 1（D0 完成后）

共振检测结果直接影响锚点 1 的原型假设：

| 共振模式 | 原型暗示 |
|---|---|
| 对多个表达者的共振都集中在"讲故事"上 | 可能偏向叙事者原型 |
| 对多个表达者的共振都集中在"提出尖锐问题"上 | 可能偏向挑衅者原型 |
| 共振从 Admiration → Recognition → Identification 逐步升级 | 候选北极星明确，锚点 1 置信度高 |
| 共振停留在 Admiration | 候选北极星不明确，锚点 1 标记为"待验证" |

### 锚点 2（D2 完成后）

用 D2（表达机制）的数据验证共振检测结果：

- 如果共振检测标记为 Identification，但 D2 发现用户的表达方式与候选北极星完全不同 → 标记为"伪认同"，重新评估
- 如果共振检测标记为 Identification，且 D2 发现用户的表达方式与候选北极星高度一致 → 标记为"真认同"，原型假设升级

## 5. 共振检测的常见误判

### 误判 1：Admiration 被误认为 Identification

**表现：** 用户说"我很佩服他"，系统误标记为 Identification。

**纠正规则：** 必须满足 Identification 的全部特征（"这就是我"的表述、身份层面的认同），不能仅凭"佩服"就升级。

### 误判 2：社会认同被误认为 Recognition

**表现：** 用户说"大家都说他好"，系统误标记为 Recognition。

**纠正规则：** Recognition 必须有**个人的情感投射**——"他说出了我想说的话"。如果用户只是在重复社会评价，不是 Recognition。

### 误判 3：一时兴趣被误认为 Direction

**表现：** 用户说"我现在很想成为这样的人"，系统误标记为 Direction。

**纠正规则：** Direction 必须有**时间承诺**——"我愿意走十年"。短期愿望不是 Direction。Round 8 的压力测试会过滤这种误判。

### 误判 4：多个共振被误认为多个北极星

**表现：** 用户对 3 个人都产生了 Identification 级别的共振，系统认为有 3 个北极星。

**纠正规则：** 北极星最终必须去人名化。如果 3 个共振点提取出的核心属性是同一个方向，它们指向同一个北极星。如果在 Round 6 去人名化后仍然有多个不相关的方向，标记为"双核北极星"（最多 2 个）。

## 6. AI 执行协议

### 6.1 实时检测

AI 在 D0 全程执行以下检查：

1. **每道题回答后**：扫描回答中的共振信号词
2. **检测到信号后**：标记共振层级，追加到 resonanceLog
3. **检测到升级时**：更新共振层级，追加记录
4. **检测到 Direction 时**：记录候选北极星，在板块结束时触发压力测试

### 6.2 共振检测不打断对话流

共振检测是**后台监听**，不是主动提问。系统不会在用户回答后说"我检测到你的共振层级是 Recognition"。

**只在以下时机向用户反馈共振检测结果：**
1. 板块结束时（作为张力检测的一部分）
2. 用户明确问"我到底被什么吸引？"
3. 北极星发现循环的 Round 6（去人名化）时

### 6.3 共振检测的输出

共振检测的结果在以下场景被使用：

| 场景 | 使用方式 |
|---|---|
| 板块结束时的张力检测 | "你欣赏的人身上反复出现的一个特质是独立思考——这和你 Q12 说不想被描述为'装'形成了有趣的张力" |
| 北极星发现循环 Round 3 | "你追溯到的这个影响源，你的共振层级比一阶人物更高——这说明什么？" |
| 北极星发现循环 Round 6 | "你反复被'独立思考'和'自由探索'吸引——这些属性来自不同的人物，但它们指向同一个方向" |
| 原型锚点 1 | "基于你的共振模式，我初步假设你的原型是 X 和 Y" |
