## 板块说明

D1 挖掘被访谈者的信念体系、立场和愿景。这是审计中最"尖锐"的板块——它直接面对一个人的价值观、反共识倾向，以及他希望世界变成什么样的深层渴望。

**这一板块在挖什么：**
你相信什么别人不信的；你的领域热见解；你的哲学立场；你希望推动什么改变。

**层级结构：**
D1 的问题组织遵循一个从内在信念到外在愿景的递进层级：

```
信念（Belief）
  ↓  "我相信世界是什么样的"
立场（Position）
  ↓  "所以我站在哪里"
愿景（Vision）
  ↓  "我希望世界变成什么样"
```

**理论锚点：**

**Fred Polak《The Image of the Future》(1950s-60s)** 是 futures studies 的重要奠基工作之一。Polak 的核心问题：一个人/社会"如何想象未来"，会不会影响它实际上走向什么未来？他提出一个强判断：一个文明如果失去了对未来的积极想象，自身的生命力也会衰退。北极星本质上是一个人脑中的「未来意象」(Future Image)——它不是目标，而是产生行动方向的源头。Polak 描述的循环 `Future Image → Present Action → Future Reality → New Future Image` 正是你一直在研究的 loop 思维。

**Peter Senge（Positive Vision / Negative Vision）** 在组织学习/系统思考中区分过：负面愿景容易变成"为了避免坏结果而行动"（avoidance motivation），正向愿景则是"我希望创造什么"。但两者结合才是完整的价值立场——不是逃跑，而是有方向的站立。相关组织研究发现，领导者的愿景可以同时描述"如果改变会得到什么"和"如果不改变会失去什么"。

**为什么需要愿景层：**
信念本身没有方向。一个人可以拥有深刻的信念但缺乏改变世界的渴望。愿景层把信念从"解释世界"提升到"改变世界"——它天然具有召集人的能力。Polak 的判断对个人同样适用：失去了对未来的积极想象，个人的表达也会失去生命力。

**依赖关系：**
高依赖 D0。D0 建立的语境底座是理解 D1 答案的前提——同样的信念在不同身份语境下权重完全不同。愿景尤其需要 D0 的身份定位作为锚点：你希望世界变成什么样，本质上是你希望"像你这样的人"在世界上处于什么样的位置。

## 问题列表

### Q19-Q23：核心信念

**Q19.** 有什么观点是你深信不疑，但大多数人（尤其是你的领域里的人）不同意的？为什么你确信？

**Q20.** 你有什么"热见解"——一个你会为之辩护到底的立场？用一句话说清楚，然后告诉我你为什么这么坚定。

**Q21.** 你的领域里有什么"公认智慧"是你认为完全错误的？不只是"有争议"，而是你真的觉得它害人不浅。

**Q22.** 有什么信念曾经彻底改变了你的表达方式或创作方法？它是什么时候种下的？

**Q23.** 你从哪个领域的知识或思维方式中获得了最大的启发——而不是你本领域的东西？

### Q24-Q27：哲学立场

**Q24.** 你的表达背后有一套哲学吗？如果有，它是什么？如果没有，你靠什么决定"什么值得说"？

**Q25.** 你的领域里有什么底层假设几乎没人质疑过？你对这个假设怎么看？

**Q26.** 在"真相"和"好故事"之间，你的表达站在哪里？你更愿意追求哪个？

**Q27.** 你认为你的表达方式在多大程度上能改变别人的想法？你的信念是什么？

### Q28-Q33：立场与演变

**Q28.** 你认同哪些你领域里的主流观点？你在哪些地方其实和大家是一致的？

**Q29.** 有什么你曾经坚信但现在不再认同的东西？什么事件或洞察改变了你？

**Q30.** 你领域里有什么争论是你觉得被过度讨论了？真正重要却被忽视的是什么？

**Q31.** 你的表达中有没有什么核心矛盾——两个你同时相信但似乎冲突的观点？

**Q32.** 如果你的表达方式有一个隐藏的议程（不是功利的，而是你真正想推动的），它是什么？

**Q33.** 如果把你所有的表达内容总结成一个最大的主张，那句话会是什么？

## 追问规则

### Q19：反共识观点

**触发追问的条件：**
- 回答过于温和（"我认为xxx可能有点问题"）→ 追问：「你说的『可能有点问题』——如果必须选边站，你站在哪边？」
- 说"其实大家都这么想" → 追问：「你真的这么认为？还是你觉得大家都这么认为？」
- 只给观点不给原因 → 追问：「为什么你确信？有什么经历或证据？」
- 观点太宽泛 → 追问：「具体在你的领域里，这个观点意味着什么？」

**追问方向：**
- 「你有没有因为这个观点被人反对过？」
- 「如果要在公开场合捍卫这个观点，你的第一句话是什么？」
- 「如果这个观点被普遍接受，世界会变成什么样？」（愿景延伸）

### Q20：热见解

**触发追问的条件：**
- 回答和 Q19 高度重叠 → 追问：「这和上一个问题有点像——但热见解和反共识不一样。热见解是你无论如何都要捍卫的，哪怕没人反对你。」
- 说"没什么热见解" → 追问：「真的吗？一定有什么事你会忍不住站出来说」
- 无法用一句话说清 → 追问：「压缩到一句话——最锋利的版本」

### Q21：公认智慧的错误

**触发追问的条件：**
- 回答变成了 Q19 的重复 → 追问：「Q19 是别人不信你的，Q21 是你觉得别人错了的——这两者的区别是：Q21 的东西你真的觉得它在害人。」
- 说"没什么" → 追问：「你的领域里一定有某种做法被所有人认为是好的，但你私下觉得是错的」
- 过于攻击性 → 不阻止，但记录：「这个回答很激烈——它在告诉你这个信念对你的重要性」

### Q22：改变表达的信念

**触发追问的条件：**
- 说"没什么特别改变过" → 追问：「仔细想想——有没有一个时刻你觉得『我再也回不去了』？」
- 只提到近期 → 追问：「那个信念是什么时候种下的？第一次出现是什么时候？」
- 回答了信念但没说它如何改变了表达 → 追问：「这个信念具体改变了你怎么说话、怎么写、怎么呈现？」

**追问方向：**
- 「那时候你是什么样的人？」
- 「如果没有那个信念，你现在会是什么表达风格？」

### Q23：跨领域启发

**触发追问的条件：**
- 说"没什么跨领域的" → 追问：「一定有的——你最常引用哪个领域的思考方式？」
- 只提到一个领域 → 追问：「还有呢？最意外的那个是什么？」
- 说是自己的领域 → 追问：「你自己的领域不算——我说的是『不是你本领域的东西』」

**追问方向：**
- 「那个领域的思维方式是怎么进入你的表达里的？」
- 「如果把你表达方式的 10% 换成那个领域的逻辑，会变成什么样？」

### Q24：表达的哲学

**触发追问的条件：**
- 说"没有哲学" → 追问：「没有哲学也是一种哲学——那个『决定什么值得说』的标准是什么？」
- 哲学过于抽象 → 追问：「这个哲学在你的表达里具体体现为什么？举个例子」
- 哲学是引用他人的 → 追问：「那是 xxx 的哲学——你自己的呢？你在哪些地方和 xxx 不一样？」

### Q25：底层假设

**触发追问的条件：**
- 说"不知道有什么假设" → 追问：「想想你的领域里大家都默认『理所当然』的事——比如『越多人看越好』『越新越好』之类的」
- 只提到技术假设 → 追问：「不是技术的——是价值观层面的假设」
- 过于批判 → 记录但不追问

### Q26：真相 vs 好故事

**触发追问的条件：**
- 说"都重要" → 追问：「但如果必须排序呢？当你发现一个真相但它不够好故事的时候，你怎么选？」
- 说"真相" → 追问：「那如果真相会让你的受众不舒服呢？你还说吗？」
- 说"好故事" → 追问：「那如果故事和真相不完全一致呢？你在哪个点停下来？」

**追问方向：**
- 「你有没有因为追求好故事而牺牲过真相？什么感觉？」
- 「反过来呢？有没有因为真相太干而放弃了？」

### Q27：改变想法的信念

**触发追问的条件：**
- 说"我不知道" → 追问：「那你为什么还在表达？」
- 过于乐观（"我能改变很多人"）→ 追问：「真的吗？有没有你尝试改变但没成功的人？」
- 过于悲观（"什么都改变不了"）→ 追问：「那你为什么还在说？如果改变不了任何人，意义是什么？」

### Q28：和主流一致的地方

**触发追问的条件：**
- 说"没什么一致的" → 追问：「不可能——你一定在有些地方和大家是一样的。想想看」
- 只提到表面共识 → 追问：「更深层的呢？价值观层面的？」
- 连续两题（Q19/Q21）都在说反共识 → 追问：「你已经连续说了三个和别人不一样的观点——有没有一个你其实和大家一样的地方？」

**追问方向：**
- 「你在哪些地方其实和大家一样，但你很少提到？」
- 「那些共识对你来说重要吗？」

### Q29：曾经坚信现在不信的

**触发追问的条件：**
- 说"没什么改变过" → 追问：「真的？三年前呢？五年前呢？」
- 改变过于近期 → 追问：「那个旧信念在你心里待了多久？」
- 只提到观点改变 → 追问：「那改变了你怎么表达吗？你的表达方式有因为那个信念而变吗？」

### Q30：被过度讨论 vs 被忽视的

**触发追问的条件：**
- 说"没什么被过度讨论的" → 追问：「你的领域里最热门的三个话题是什么？它们真的重要吗？」
- 只列了一个被忽视的 → 追问：「还有呢？你观察到的第二个呢？」
- 回答变成了抱怨 → 不阻止，但追问：「那你在做什么来改变这个？」

### Q31：核心矛盾

**触发追问的条件：**
- 说"没什么矛盾" → 追问：「一定有的——两个你同时相信但好像打架的观点。想想看」
- 矛盾过于抽象 → 追问：「这个矛盾在你的日常表达里具体体现为什么？」
- 试图消解矛盾 → 不阻止，但记录：「你在尝试统一它们——但这个矛盾可能就是你的独特性的来源」

**追问方向：**
- 「这两个观点能同时存在吗？还是你必须选一个？」
- 「这个矛盾是什么时候出现的？」

### Q32：隐藏议程

**触发追问的条件：**
- 说"没什么议程" → 追问：「不是功利的——是你真正想推动的。如果你可以让所有人都接受一个想法，那会是什么？」
- 议程过于功利（"想让更多人知道我"）→ 追问：「再深一层——知道之后呢？你想让他们做什么？」
-  agenda 是负面的 → 不阻止，记录到 tensionLog

**愿景延伸追问：**
- 「如果这个议程真的实现了，世界会变成什么样？」
- 「谁会从中受益？谁会受到影响？」
- 「这个愿景和你自己的经历有什么关系？」

### Q33：最大主张

**触发追问的条件：**
- 主张过于宽泛（"要做更好的自己"）→ 追问：「太宽了——压缩到一句话，只能有一个核心动作」
- 主张是引用他人的 → 追问：「那是 xxx 的主张——你自己的呢？」
- 主张和 Q19 的回答高度重叠 → 正常——这是预期的。记录这个重叠。

**追问方向：**
- 「如果有人反对这句话，你觉得他们会说什么？」
- 「这句话能印在你的所有作品下面吗？」
- 「如果这个主张真的被所有人接受，世界会发生什么变化？」（愿景延伸）
- 「你希望通过这个主张让谁发生什么改变？」（愿景延伸）

**愿景收敛触发条件：**
当系统检测到 Q32/Q33 的回答中包含以下信号时，自动触发愿景收敛追问：
- 回答中出现"我希望""我期待""我想看到"等未来指向词
- 回答中提到了受众/人群的改变（"让人们..."）
- 回答和 D0 的身份陈述形成呼应

**愿景收敛追问：**
- 「你说『希望人们...』——具体是哪类人？他们现在是什么样，你想让他们变成什么样？」
- 「这个改变发生后，世界哪个方面会不一样？」
- 「如果有一天这个愿景实现了，你回头看你现在的表达，会觉得它们起到了什么作用？」
